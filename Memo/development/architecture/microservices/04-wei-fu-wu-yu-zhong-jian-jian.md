# 04 微服务与中间件

> 聚合自微服务阶段全部课程资料与个人 MQ 笔记，去除课程示例项目的业务细节，只保留技术知识与方案。

## 一、微服务架构基础

- 单体架构 vs 微服务架构的演进与取舍
- 微服务拆分思路：按业务功能划分服务边界
- Spring Cloud 与 Spring Cloud Alibaba 的区别和联系
- Spring Boot 与 Spring Cloud 的关系（面试高频）

## 二、服务注册发现与远程调用

- 服务注册与发现的完整流程
- 远程调用技术选型：RestTemplate 的使用与局限
- OpenFeign 的工作原理与最佳实践
- Nginx 负载均衡；为什么叫"反向代理"

## 三、服务保护

- 微服务保护的常用方案
- Sentinel 熔断降级
- 请求限流
- 线程隔离

## 四、分布式事务

- 什么是分布式事务；CAP 原理
- Seata 安装与上手
- Seata 四大核心模式详解对比：AT / TCC / XA / SAGA

  - 四大模式的核心定义与设计初衷
  - 底层执行逻辑差异
  - 12 个关键指标横向对比
  - 典型适用场景与选型建议
  - 共同注意事项

## 五、网关与配置中心

- 认识网关与网关路由的实现
- 网关鉴权：内置过滤器（全局过滤器 vs 路由过滤器核心区别）
- 自定义过滤器与身份校验过滤器
- 网关向下游传递用户信息

## 六、消息队列（MQ）

### MQ 基础

- 同步调用与异步调用的对比；MQ 的应用场景
- RabbitMQ 介绍、安装、收发消息、数据隔离
- 工作模型：普通队列、工作队列（Work Queue）、发布订阅
- 交换机类型
- 如何解决 MQ 消息堆积问题

### MQ 高级

- 消息可靠性三板斧：

  - 生产端可靠性
  - 消息持久化（交换机 / 队列 / 消息三级持久化）
  - 消费端可靠性与业务补偿
- 延迟消息：死信交换机（DLX）+ TTL 方案、延迟消息插件、超时未支付订单自动取消
- RabbitMQ 集群：普通集群、镜像模式、仲裁队列的搭建与特点

## 七、Elasticsearch

- 认识 ES 与安装；基础概念
- IK 分词器
- Mapping 映射属性、索引的创建 / 查询 / 修改
- DSL 查询与聚合
- 高级：算分函数（function_score）、深度分页、地理坐标查询
- 同义词设置与自定义分词器
- 自动补全（completion suggester）

## 八、缓存体系

- 缓存应用入门；Spring Cache 集成
- 缓存一致性问题及方案
- 缓存穿透 / 击穿 / 雪崩三大问题与对策（面试高频）
- 分布式锁入门
- Redis 持久化：RDB 与 AOF 对比
- Redis 集群：主从复制、哨兵（failover 演示）、分片集群搭建与 Java 客户端接入

## 九、任务调度

- 什么是任务调度
- XXL-JOB 搭建与任务入门
- 分片广播任务
- 热点数据定时预热任务设计

## 十、数据同步

- ES 索引同步的技术方案分析
- Canal + MQ 数据同步方案：MySQL 主从同步配置、Canal 安装、队列配置、同步测试
- 常见故障：数据不同步、MQ 同步消息无法消费的排查
