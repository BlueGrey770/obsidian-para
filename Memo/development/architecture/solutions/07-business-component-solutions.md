# 07 业务组件方案集

> 从各实战项目中提取的**通用组件方案**，已脱敏：不出现任何具体项目名称，仅保留"场景 → 技术要点 → 关键组件"的方案骨架，便于在新项目中直接复用。

## 一、认证授权方案

- 场景：后台管理系统 + 小程序多端认证
- 要点：RBAC 权限模型、Spring Security、第三方登录（微信）、小程序登录流程
- 组件：用户上下文（ThreadLocal）、网关身份校验过滤器

## 二、对象存储与文件上传方案

- 场景：图片 / 文件的上传与外链访问
- 要点：对象存储（OSS）集成、依赖配置、上传下载 API
- 组件：OSS SDK、文件上传接口规范

## 三、缓存应用方案

- 场景：门户首页等高并发读多写少场景
- 要点：Spring Cache 注解式缓存、缓存一致性、穿透 / 击穿 / 雪崩防护
- 组件：Redis、Spring Cache

## 四、定时任务方案

- 场景：定时更新业务状态（如合同状态、超时订单）
- 要点：cron 表达式、Spring Task 入门、脚手架框架中的定时任务配置、XXL-JOB 分片广播
- 组件：Spring Task、XXL-JOB

## 五、实时通知方案

- 场景：报警 / 通知的实时推送
- 要点：WebSocket 服务端推送、消息过滤与处理
- 组件：WebSocket

## 六、IoT 设备接入与数据处理方案

- 场景：智能设备（定位手表、烟雾报警器、监测带等）接入与告警
- 要点：华为云 IoT 平台设备管理、物模型、设备数据转发、异步处理、报警规则与数据过滤、设备数据模拟上报脚本
- 组件：华为云 IoT、异步任务、WebSocket 告警

## 七、搜索方案

- 场景：服务 / 商品的关键词搜索
- 要点：ES 索引结构设计、数据同步方案（Canal + MQ）、搜索接口定义、聚合与过滤
- 组件：Elasticsearch、Canal、RabbitMQ

## 八、订单系统方案

- 场景：下单、取消、状态流转
- 要点：订单状态机设计与实现、分库分表（ShardingSphere-JDBC）、订单查询优化、超时未支付自动取消（延迟消息）
- 组件：状态机、ShardingSphere、MQ 延迟消息

## 九、秒杀抢购方案

- 场景：限量资源的高并发抢购
- 要点：秒杀业务特点与常用技术方案、活动查询、抢购流程、结果异步同步
- 组件：Redis、MQ

## 十、派单调度方案

- 场景：订单向服务提供者的智能派发
- 要点：调度流程、责任链模式、派单策略定义、派单池同步
- 组件：责任链模式、定时调度

## 十一、支付集成方案

- 场景：小程序 / 网页支付
- 要点：微信支付接口调研（小程序支付、Native 支付总体流程）、下单与调起支付、支付通知接收、商户侧按订单号查询
- 组件：微信支付 API

## 十二、优惠券方案

- 场景：发券、领券、核销
- 要点：业务流程梳理、表结构设计、数据流设计
- 组件：数据库设计、MQ（结果同步）

## 十三、数据导入导出方案

- 场景：Excel 批量导入导出
- 要点：EasyExcel 读写、Web 上传下载集成
- 组件：EasyExcel

## 十四、快速开发脚手架方案

- 场景：基于开源脚手架快速搭建业务系统
- 要点：脚手架项目结构与快速开发流程、代码生成与模板改造、UI 主题定制、操作日志处理流程、前后端联调模式
- 组件：开源管理脚手架、代码生成器

## 十五、AI 业务能力集成方案

- 场景：传统业务系统接入大模型能力（智能评估、智能问答、智能客服）
- 要点：Function Calling 打通业务接口、提示词工程、RAG 知识库对接、智能体平台（Dify / Coze）与业务系统对接
- 组件：Spring AI、Dify、RAGFlow
