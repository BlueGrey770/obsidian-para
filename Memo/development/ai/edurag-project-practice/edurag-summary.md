# EduRAG-总结

<whiteboard token="WHFYwnl5UhJONVbwDlAca84Lnzc"></whiteboard>

- 首先在启动的时候需要初始化向量数据和Mysql中的FAQ
- **初始化Mysql数据。**提前在Mysql中会存入用户常用的问题，这个数据一共也就几百条，将所有**问题**查询出来。先利用**jieba**这个工具进行分词，然后将分词的数据交给**BM25**
- **初始化Milvus向量数据库**

  - **加载文档**。提前准备好一个数据目录，分为ai文档还有java文档等。递归查询这个目录下的所有的文档，支持txt、pdf、图片、md、doc等。根据不同的文档类型获取不同的加载器，进行加载文档。
  - **分割文档。**接下来进行文档分割，获取到四种**分割器**（普通文本的父分割器、普通文本的子分割器，MarkDown文档的分割器，MarkDown文档的子分割器），**父文本分割器最大字符数1300**，**子文本分割器最大字符数400**，根据文档类型的不同，获取到对应的分割器。**先进行父文本的分割**，遍历每个父文本块，生成父文本的id（文档的索引拼接当前父块的索引），**再对当前这个父块进一步分割，分割成若干子块**。再遍历每个子块，在子块中添加父文块的id和内容，同时生成当前字块儿的id（文档索引 + 父块索引+子块索引）。将来字块儿进行向量化检索，父块用来提供给大模型，保证上下文一致
  - **存入向量数据库。**利用**bge-m3模型**对所有的**子块儿进行向量化**，获取到**稠密向量**和**稀疏向量。**接下来就可以保存到**Milvus向量数据库，**将来保存的字段包含**id（对文档内容md5加密）**、**子文档内容**、**稠密向量**、**稀疏向量**、**父文档的id**、**父文档的内容、学科**
- **初始化Bert二分类模型。**提前准备一批样本数据，包含**通用知识**和**专业知识**，利用**bert-base-chinese基础模型**进行训练，得到bert_results训练好的模型，准确率能够达到88%
- 初始化动作准备好之后，接下来开始进行检索，用户输入问题后，先根据问题去**Redis**中查询答案，如果redis中存在，直接返回。如果没有，就需要去Mysql或者Milvus中进行查询
- **Mysql查询。**首先对用户的问题利用**jieba**进行分词，再利用**BM25**进行算分（算出来的是所有数据库中的问题和当前用户的问题的相关度分数），利用**softmax函数**进行归一化（对得到的分数聚合为0-1之间）。获取到最高的分数，如果超过我们规定的阈值（0.9），那么就认为数据库中包含相关的问题，获取该问题根据问题去**Mysql**中查询对应的答案，存入**Redis**并直接返回给用户。如果Mysql中未查询相关的问题，走RAG系统查询
- **RAG系统查询。**

  - 首先利用训练好的**Bert模型**对用户的问题进行二分类，分为**通用知识**和**专业知识**两类。
  - 如果是**通用知识**，利用**langChain**框架提供的**PromptTemplate提示词模板**直接拼接提示词，拼接好之后利用**langChain**直接调用**qwen-plus**大模型，得到大模型的结果返回给用户
  - 如果是**专业知识**，先从**Milvus**向量库进行查询，先对用户问的问题进行向量化，获取到**稠密向量**和**稀疏向量，**分别构建AnnSearchRequest请求对象，并指定权重稠密向量是1，稀疏向量0.7，调用Milvus里的**混合检索，**对结果按照父文档进行去重，如果文档数量小于2直接返回即可，如果文档数量大于2，利用**reranker**模型，进行重排序返回2个相关度最高的文档。利用**langChain**框架提供的**PromptTemplate提示词模板**直接拼接获取到的文档到对应的提示词，拼接好之后利用**langChain**直接调用**qwen-plus**大模型，得到大模型的结果返回给用户。
