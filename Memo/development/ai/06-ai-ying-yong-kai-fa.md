# 06 AI 应用开发

> 聚合自 SpringAI、Python 大模型开发与私有化部署三条学习线的全部材料，按"原理 → 框架 → 工程化"组织。

## 一、大模型基础

- 人工智能发展脉络
- 大模型原理（训练、推理、推理模型）
- 大模型应用开发的技术架构与选型

## 二、大模型服务接入

- 公共大模型：DeepSeek
- 公共大模型平台：阿里百炼
- 本地部署：Ollama
- 使用 OpenAI 协议在 API 工具（Apifox）中调用大模型
- 私有化大模型部署方案
- 百度智能云等云厂商模型服务的接入方式

## 三、Spring AI（Java 方向）

- 快速入门：对话机器人的搭建
- ChatClient 的配置与使用
- 日志功能
- 会话记忆与会话历史管理
- 对接前端
- 提示词工程：编写提示词、提示词攻击防范（如角色扮演类应用的防注入）
- Function Calling / Tool Calling：以智能客服为例的思路分析与实现
- RAG：原理、PDF 上传下载与向量化、对话接口
- Spring AI Alibaba：工程创建、依赖、ChatClient、推理模型、响应格式、自定义 Advisor 处理思考过程
- MCP：什么是 MCP、技术架构、MCP Client / Server 实战、在 AI 编程 IDE（Trae）中集成 MCP

## 四、LangChain（Python 方向）

- LangChain 概述：核心功能、应用场景、架构与常见组件
- Models 组件：消息类型、调用本地大模型（Ollama）与云平台大模型
- Prompts 组件：字符串提示模板

## 五、RAG 系统实战（教育领域问答系统）

- 向量数据库 Milvus：安装、核心概念、索引、相似度度量、基本操作
- 文档存储：加载文档、拆分文件、向量化存储
- 文档检索流程
- 提示词检索：查询问题分类、提示词模板、多策略提示词、主流程融合
- 系统优化：BM25 算法混合检索、数据初始化、问题搜索
- 流式输出、会话记忆（会话记忆表设计）、对接前端
- 系统评估：评估框架、参评数据、评估指标、评估脚本

## 六、LangGraph

- Chain 与 Graph 的对比
- 图的基本组成：图、状态、节点、边、记忆
- 流程控制：分支等

## 七、平台智能体

- 什么是智能体
- Coze 平台：智能问答助手搭建
- Dify：环境搭建（docker-compose、镜像加载、接入大模型）、工作流案例（微调语料构建）、RAG 知识库、工具集成、接入 MCP
- RAGFlow：镜像准备、部署、接入大模型
- 智能体平台与业务系统的对接案例（如业务系统对接 Dify）

## 八、Python 基础（AI 方向）

- Python 特点、应用领域与环境搭建（Anaconda、PyCharm）
- 基础语法与运算符
- 面向对象：类与对象、封装、继承、多态
- 异常处理与模块
- FastAPI Web 开发入门
