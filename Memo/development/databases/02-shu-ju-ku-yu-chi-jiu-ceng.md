## 二、数据类型与设计规范

- MySQL 常见数据类型（整数 / 字符串 / 时间 / 金额类型的选择原则）
- 团队表设计规范：

  - 表名小写字母加下划线，体现业务含义，避免保留字
  - 主键统一命名 `id`，外键命名 `关联表名_id`
  - 布尔字段以 `is_` 开头，时间字段以 `_time` 结尾
  - 金额使用 DECIMAL，避免 FLOAT / DOUBLE
  - 主键 NOT NULL + AUTO_INCREMENT，必填字段 NOT NULL，唯一字段加唯一约束
