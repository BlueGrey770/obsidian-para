# 函数进阶

## 概念说明

掌握了函数的定义、参数和返回值之后，还有一组进阶用法让函数更灵活：一次返回多个结果、用四种不同方式传参（位置、关键字、缺省、不定长），以及把函数当作「值」来使用（lambda 匿名函数、函数作为参数传递、闭包）。这些特性让函数从「固定写死的代码块」变成「可组合、可配置的逻辑单元」。

## 技术点之间的联系

本篇建立在函数基础之上：多返回值是 return 的扩展用法，四种传参方式是形参/实参对应规则的细化。不定长参数中的 `*args`（元组）和 `**kwargs`（字典）直接用到数据容器一篇的知识——传参的本质就是打包成容器。lambda 与闭包则是通往函数式编程和装饰器的桥梁，在后续框架学习中会频繁遇到。

## 方法与实现要点

### 多返回值

- 一个函数写两个 return，只会执行第一个——return 会退出当前函数，其下方代码不再执行
- 要返回多个值：`return 值1, 值2`，用逗号隔开，**支持不同类型的数据一起 return**
- 接收时按返回值的顺序，写对应顺序的多个变量，逗号隔开：`a, b = func()`

### 四种传参方式

| 方式 | 定义 | 要点 |
|---|---|---|
| 位置参数 | 调用时按参数位置传递 | 传参与定义的**顺序和个数必须一致** |
| 关键字参数 | 调用时用「键=值」形式传递 | 参数清晰、不要求顺序；与位置参数混用时，位置参数必须在关键字参数前面，关键字参数之间无先后顺序 |
| 缺省参数（默认参数） | 定义时为参数提供默认值 | 调用时不传该参数就用默认值，传了则覆盖；**所有位置参数必须出现在默认参数之前**（定义和调用均是） |
| 不定长参数（可变参数） | 不确定会传多少个参数（不传也可以） | 分位置传递和关键字传递两种 |

不定长参数的两种形态：

```python
def 函数名(*args):     # 位置传递：所有传入参数按位置合并为一个元组(tuple)，交给args
    ...

def 函数名(**kwargs):  # 关键字传递：所有「键=值」被kwargs接受，组成字典(dict)
    ...
```

约定俗成的命名是 args 和 kwargs（可改但不建议）。

### 扩展概念：lambda、函数作参数、闭包

这三个概念在基础语法之后用于更抽象的代码组织：

- **lambda 匿名函数**：用 `lambda 参数: 表达式` 定义只有一个表达式的小型函数，不需要 def 和函数名，常作为一次性的小逻辑传给其他函数使用。
- **函数作为参数**：函数在 Python 中是一等公民，本身也是数据，可以赋值给变量、作为参数传给另一个函数——这让「排序规则」「处理方式」这类策略可以在调用时才注入。
- **闭包**：在嵌套函数中，内层函数引用了外层函数的变量，并且外层函数把内层函数作为返回值返回，就形成了闭包。闭包让内层函数「记住」了外层变量的状态，是装饰器的底层原理。

当前阶段先建立概念印象即可，具体语法在面向对象与进阶专题中展开。

## 重点与难点分析

- **return 即终结**：多返回值不是写多个 return，而是 `return a, b` 一行搞定——其本质是把多个值打包成一个元组返回，接收时的 `a, b = func()` 就是元组解包。
- **位置参数的刚性**：顺序和个数都不能错，这是最容易在调用时犯的错；参数一多就改用关键字参数提高可读性。
- **缺省参数的位置约束**：带默认值的参数必须定义在最后，否则 Python 无法判断传入的值对应哪个形参，直接报语法错误。
- **args 是元组、kwargs 是字典**：记住收集结果的类型，函数体内就要按对应容器的方式处理（args 可遍历可索引，kwargs 按键取值）。
- **混用顺序**：定义和调用时都遵循「位置参数 → 关键字参数/缺省参数 → 不定长参数」的次序，位置永远在前。
- **lambda 不是 def 的替代品**：只适合一行表达式能写完的逻辑；逻辑稍复杂就回到 def，否则可读性急剧下降。

## 示例

多返回值的定义与接收（素材取自真实练习代码）：

```python
def compareNum(nums):
    """
    接收列表参数，返回列表中的最大值和最小值
    :param nums: list类型的参数，列表中的元素必须为数字（int或float）
    :return: 返回值的第一个参数是该列表中的最大值，第二个参数为该列表的最小值
    """
    # 先把列表的第一个元素定义为最大最小值，方便后续比较
    num_Max = nums[0]
    num_Min = nums[0]
    for i in nums:
        # 当前数比最大值大，将num_Max更新
        if i > num_Max:
            num_Max = i
        # 当前数比最小值小，将num_Min更新
        if i < num_Min:
            num_Min = i
    return num_Max, num_Min  # 一行return多个值，支持不同类型

nums = [1, 2, 3, 4, 5, 6]
max_num, min_num = compareNum(nums)  # 按返回值顺序，用多个变量接收
print(max_num, min_num)              # 6 1
```

这段演示什么：多返回值的标准写法——`return a, b` 返回、`a, b = func()` 按序接收；注意函数说明文档里明确写出两个返回值的含义，是多返回值函数的良好习惯。

不定长参数的两种收集形态（语法骨架）：

```python
def demo(*args, **kwargs):
    print(args)    # 位置传递的参数被收集成元组
    print(kwargs)  # 关键字传递的参数被收集成字典

demo(1, 2, 3, name="张三", age=18)
# args    -> (1, 2, 3)
# kwargs  -> {'name': '张三', 'age': 18}
```

这段演示什么：`*args` 按位置打包成 tuple、`**kwargs` 按「键=值」打包成 dict；形参列表中二者可以同时出现，分别接住两种形态的实参。
