# 函数基础

## 概念说明

函数是组织好的、可重复使用的、用来实现特定功能的代码段。我们已经用过的 input()、print()、str()、int()、len() 都是 Python 的内置函数——提前写好、可以重复调用。自定义函数的意义在于：把一段针对特定需求的逻辑封装起来，随时随地重复利用，提高代码复用性、减少重复代码、提高开发效率。

## 技术点之间的联系

函数把前面学过的所有内容（变量、运算符、判断、循环）打包成可复用的单元；参数让函数能接受外部数据，返回值让函数能把结果交还给调用者——这正是 input/print 思维在代码组织层面的延伸。作用域规则（局部变量、全局变量、global）则解释了函数内外变量的可见性，与 for 循环临时变量的作用域一脉相承。后续的数据容器方法（如 `列表.append()`）本质上就是绑定在对象上的函数。

## 方法与实现要点

### 定义与调用

```python
def 函数名(参数列表):
    函数体
    return 返回值   # 可有可无

函数名(参数列表)     # 调用
```

注意：

- **先定义，后调用**
- 参数不需要可省略，返回值不需要可省略
- 中括号 `[...]` 在语法描述里表示「可有可无」

### 参数

- 传入参数的作用：函数进行计算时，接受外部（调用时）提供的数据
- **形参**：函数定义中声明的参数（如 x、y）；**实参**：函数调用时真正传入的值（如 5、6）
- 参数数量不限，逗号分隔；传入时按顺序与形参一一对应

### 返回值

- 函数执行完成后返回给调用者的结果，用 `return` 关键字返回
- 返回值建议用变量接收：`max_num = getMax(num1, num2)`
- **函数体遇到 return 就结束了**，return 后同级别的代码不会执行

参数与返回值的四种组合：有参有返回值、有参无返回值、无参有返回值、无参无返回值（最后一种一般用于打印类功能）。

### None 类型

- None 是类型 `NoneType` 的字面量，表示「空的、无实际意义」
- 不写 return 的函数，实际返回的就是 None；主动写 `return None` 效果相同
- 使用场景：函数返回值占位、if 判断、变量初始化

### 函数说明文档

用多行注释对函数进行说明，**必须写在函数体有效代码的第一行**：

```python
def 函数名(参数):
    """
    功能说明
    :param 参数名: 参数说明
    :return: 返回值说明
    """
```

在 PyCharm 中鼠标悬停函数名即可查看；也可用 `help(函数名)` 在控制台打印说明文档。

### 函数的嵌套调用

一个函数里面调用另一个函数。执行流程：函数 A 执行到调用函数 B 的语句时，会把函数 B 全部执行完后，再继续执行函数 A 的剩余内容。

### 变量作用域

| 类型 | 定义位置 | 生效范围 |
|---|---|---|
| 局部变量 | 函数体内部（判断体、循环体同理） | 只在函数体内部，函数调用完成后销毁 |
| 全局变量 | py 文件中顶格定义 | 整个 py 文件，函数内外都能用 |

- 函数内读取变量遵循**就近原则**：局部有就用局部，局部没有才找全局
- 函数内直接 `num = 200` 是定义同名局部变量，**不会**修改全局变量
- 要在函数内修改全局变量，先用 `global 变量名` 声明，再赋值

## 重点与难点分析

- **return 的双重身份**：既返回值、又终止函数。利用「return 后代码不执行」可以提前退出函数（如在校验失败时直接 return）。
- **无返回值 ≠ 没有返回值**：不写 return 的函数返回 None，用变量接收后打印会看到 `None <class 'NoneType'>`，不要误以为是程序出错。
- **同名遮蔽**：函数内 `num = 200` 只是新建局部变量，全局的 num 纹丝不动——这是「想改全局却改不动」bug 的根源，需要 global。
- **global 的写法是两行**：先 `global num` 声明，再 `num = 200` 赋值，不能合并成 `global num = 200`。
- **形参名与实参名无关**：参数传递靠位置顺序对应，不靠名字；形参可以随意起名。
- **说明文档的位置敏感**：三引号必须放在函数体第一行，写在别处就只是一段普通字符串，help() 读不到。

## 示例

有参有返回值：求两个数的最大值

```python
# 键盘录入两个数值
num1 = int(input("请输入您要比对的第一个数字："))
num2 = int(input("请输入您要比对的第二个数字："))
# 定义函数，用来实现求两个数最大值
def getMax(x, y):       # x和y是形式参数（形参）
    if x > y:
        return x
    else:
        return y
# 调用函数，用变量接收返回值
max_num = getMax(num1, num2)  # num1和num2是实际参数（实参）
print(f"{num1}和{num2}最大值是：{max_num}")
```

这段演示什么：函数定义/调用的完整流程，形参与实参按位置对应，return 把结果交还给调用者。

无返回值函数返回 None：

```python
def print_jiujiu2():
    num1 = 1
    while num1 <= 9:
        num2 = 1
        while num2 <= num1:
            print(f"{num2} * {num1} = {num1 * num2}", end="\t")
            num2 += 1
        num1 += 1
        print()

none_value2 = print_jiujiu2()
print(none_value2, type(none_value2))  # None <class 'NoneType'>
```

这段演示什么：函数内可以是任意复杂逻辑（嵌套循环打印乘法表）；不写 return 时接收到的返回值是 None。

带说明文档的函数：

```python
def getMax(num1, num2):
    """
    该函数主要是用来对两个参数的求最大值
    :param num1: 要对比的第一个int类型参数
    :param num2: 要对比的第二个int类型参数
    :return: 返回两个数的最大值
    """
    if num1 > num2:
        return num1
    else:
        return num2

help(getMax)  # 直接执行即可在控制台查看说明文档，不需要print
```

这段演示什么：说明文档的三引号写法、:param 与 :return 约定，以及 help() 的查看方式。

函数的嵌套调用：

```python
def func_b():
    print("----2----")

def func_a():
    print("----1----")
    func_b()          # A中调用B，B执行完再回到A
    print("----3----")

func_a()  # 输出：----1----  ----2----  ----3----
```

这段演示什么：嵌套调用的执行顺序——调用语句处「暂停 A、跑完 B、再续 A」。

局部变量与全局变量、global 关键字：

```python
num = 100  # 全局变量

def func_a():
    global num  # 声明num为全局变量，之后的赋值会修改全局
    num = 200
    print(num)  # 200

def func_b():
    print(num)  # 局部没有num，找全局；由于func_a已修改全局，打印200

func_a()  # 200
func_b()  # 200
```

这段演示什么：不用 global 时 func_a 内的 `num = 200` 只是局部变量（func_b 仍打印 100）；加了 global 声明后，函数内赋值直接改写全局变量。

函数返回多值（多返回值预览）：

```python
def compareNum(nums):
    """
    接收列表参数，返回列表中的最大值和最小值
    :param nums: list类型的参数，元素必须为数字
    :return: 第一个返回值是最大值，第二个是最小值
    """
    num_Max = nums[0]
    num_Min = nums[0]
    for i in nums:
        if i > num_Max:
            num_Max = i
        if i < num_Min:
            num_Min = i
    return num_Max, num_Min  # 一行return多个值

nums = [1, 2, 3, 4, 5, 6]
compare = compareNum(nums)
print(compare)
```

这段演示什么：函数与 for 循环、if 判断的综合运用；`return a, b` 一次返回多个结果（进阶篇会详解多返回值与多种传参方式）。
