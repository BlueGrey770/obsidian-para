# 计算机组成与 Python 概述

## 概念说明

计算机是一台存储和计算数据的电子设备：能进行数值计算与逻辑判断，具有存储记忆功能，并能按照程序自动、高速地处理数据。理解计算机的组成和编程语言的角色，是写出第一行 Python 代码之前的必要背景知识。

编程语言（programming language）是计算机和人都能识别的语言，作用是让人能够准确地定义计算机需要使用的数据，并精确地定义在不同情况下应当采取的行动。Python 是其中一种：1991 年由吉多·范·罗苏姆（Guido van Rossum）发布了第一个编译器，名字来自他喜爱的电视剧 *Monty Python's Flying Circus*，设计初衷是让开发人员把精力放在解决问题上，而不是编程语言本身上。

## 技术点之间的联系

本篇是整个知识库的入口：硬件与软件的分工解释了「程序为什么能跑起来」，编程语言的演进解释了「为什么 Python 长这个样子」，而环境搭建则是后续所有语法实践的前提。后续篇章默认你已经装好解释器和编辑器，能新建并运行一个 `.py` 文件。

## 方法与实现要点

### 计算机系统

计算机系统分为两大部分：

- **硬件系统**：从世界上第一台计算机 ENIAC 到今天最先进的计算机，设计都采用**冯·诺依曼体系结构**，包含五大部件：
  - 运算器：负责数据的算术运算和逻辑运算，即数据的加工处理
  - 控制器：整个计算机的中枢神经，协调各组件工作（运算器 + 控制器合称 CPU）
  - 存储器：实现记忆功能，存储程序、数据、信号、命令等信息，分内存储器与外存储器
  - 输入设备 / 输出设备
- **软件系统**：
  - 系统软件：操作系统（管理和控制计算机软硬件资源，是所有软件的基础和核心）、编译程序（把编程语言写成的程序翻译成计算机可执行的机器语言）等，起承上启下的作用
  - 应用软件：音乐播放器、游戏等直接满足用户需求的软件

### 编程语言的演进

| 时代 | 时间 | 特点 | 代表语言 |
|---|---|---|---|
| 低级语言 | 1946–1953 | 机器语言与汇编语言，被称为「天书」 | 机器语言、汇编 |
| 高级语言 | 1954 至今 | 全世界涌现出 2500 种以上高级语言，一些流行至今，一些逐渐消失 | C、BASIC、Fortran |
| 面向对象 | 90 年代初至今 | 突出特点是封装性、继承性和多态性 | Java、Python |

### Python 的优缺点

优点：

- **简单**：代表简单主义思想的语言，阅读良好的 Python 程序就像在读英语，使你专注于解决问题而不是语言本身
- **易学**：语法极其简单，只有 33 个关键字、7 种基本数据类型，接近自然语言
- **免费、开源**：可以自由阅读源代码并做改动，由社区持续改进
- **可移植性**：由于开源本质，已被移植到许多平台，避免使用依赖系统的特性时，程序无需修改即可跨平台运行
- **丰富的库**：标准库覆盖正则表达式、单元测试、线程、数据库、电子邮件、XML、GUI 等，安装 Python 即可用，被称为「功能齐全」理念

缺点：执行效率慢。这是解释型语言的通病，会随着计算机性能的提升被弥补。

### Python 的应用场景

Web 应用开发、大数据开发、网络爬虫、人工智能、自动化运维、自动化测试等。知名的机器学习与深度学习框架多基于 Python 开发，如 TensorFlow、Scikit-learn、Paddle。

### 环境搭建与第一个程序

安装注意事项：

- 安装的全路径不能出现任何非英文字符
- 安装开发类软件时建议右键「以管理员身份运行」
- 配置环境变量时，除自己添加的内容外一律不要删除，误删可能导致需要重装系统

使用 PyCharm 编写第一个程序的步骤：Create New Project → 设置项目目录并选择解释器版本 → 右键项目 New → Python File → 输入文件名 → 在编辑区写代码后右键 Run。

## 重点与难点分析

- **「解释型」是理解 Python 缺点的关键**：Python 写一行、解释一行、执行一行，因此执行效率低于编译型语言。这也是它开发效率高、跨平台容易的原因——优缺点是同一个特征的两面。
- **操作系统是系统软件，不是应用软件**：操作系统管理软硬件资源，是所有软件的基础和核心；编译程序也属于系统软件，负责把高级语言翻译成机器语言。
- **冯·诺依曼体系结构是通用答案**：从第一台计算机到今天，硬件设计都遵循这一结构，记住五大部件即可覆盖大多数相关提问。
- **环境变量不要乱删**：环境变量中除自己添加的条目外一律不动，这是新手最容易踩的系统级坑。

## 示例

第一个 Python 程序，演示 print 的基本输出：

```python
print("hello world")
# 单行注释，快速向下复制一行:ctrl + d
print("hello python")
```

这段演示什么：Python 程序的入口就是一行可执行语句，`print()` 把内容输出到控制台；`#` 开头的行是注释，不会被执行。
