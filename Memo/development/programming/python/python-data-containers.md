# 数据容器

## 概念说明

一个变量只能存一份数据，要记录一个班级 100 位学生的姓名，声明 100 个变量显然不现实。数据容器是可以容纳多份数据的数据类型，容纳的每一份数据称为一个**元素**。Python 有五类数据容器：**list（列表）、tuple（元组）、str（字符串）、set（集合）、dict（字典）**，它们按「是否有序、是否支持重复元素、是否可以修改」三个维度划分出各自的适用场景。

## 技术点之间的联系

for 循环一篇提到的「可迭代对象」在这里全面落地：五类容器都支持 for 遍历，支持下标索引的（list、tuple、str）还能用 while。函数一篇的方法调用格式 `对象.方法(参数)` 是操作容器的基本方式。容器之间的嵌套（列表套字典、字典套列表）则是综合实战（如学生管理系统）组织数据的标准做法。

## 方法与实现要点

### 总览：五类容器对比

|  | 列表 list | 元组 tuple | 字符串 str | 集合 set | 字典 dict |
|---|---|---|---|---|---|
| 定义符号 | [] | () | "" / '' | {} | {}（键值对） |
| 元素类型 | 任意 | 任意 | 仅字符 | 任意（须可 hash） | Key:Value 键值对 |
| 下标索引 | 支持 | 支持 | 支持 | 不支持 | 不支持（按 Key 取） |
| 重复元素 | 支持 | 支持 | 支持 | 不支持 | Key 不重复 |
| 可修改 | 支持 | 不支持 | 不支持 | 支持 | 支持 |
| 数据有序 | 是 | 是 | 是 | 否 | 否 |
| while 遍历 | 可以 | 可以 | 可以 | 不可以 | 不可以 |

### 下标索引（序列通用）

- 从前向后：从 0 开始递增，最大值是「元素个数 - 1」
- 从后向前（反向索引）：从 -1 开始递减
- 取值：`容器[下标]`；下标超出范围会报错（索引越界）
- 嵌套容器逐级取：`names[2][2]`

### list 列表

定义三种方式：`[元素1, 元素2]`、`[]`、`list()`。元素类型无限制，支持嵌套。

常用方法：

| 使用方式 | 作用 | 返回值 |
|---|---|---|
| 列表.append(元素) | 把元素作为整体追加到尾部 | None |
| 列表.extend(容器) | 把容器内元素逐个取出追加到尾部 | None |
| 列表.insert(下标, 元素) | 在指定下标处插入元素（下标必须给） | None |
| del 列表[下标] | 删除指定下标元素（del 列表 可删整个列表） | — |
| 列表.pop(下标) | 删除指定下标元素；pop() 默认删最后一个 | 被删除的元素 |
| 列表.remove(元素) | 从前向后删除第一个匹配项，元素不存在报错 | None |
| 列表.clear() | 清空列表 | None |
| 列表.count(元素) | 统计元素出现次数，不存在返回 0 | int |
| 列表.index(元素) | 查找元素下标，找不到报错 ValueError | int |
| 列表[下标] = 新值 | 修改指定位置元素 | — |
| len(列表) | 统计元素个数 | int |

列表特点：可容纳多个元素（上限 2**63-1）、类型可混装、有序、允许重复、可修改。

### tuple 元组

定义：`(元素1, 元素2)`、`()`、`tuple()`。**只有一个元素时必须在元素后加逗号**：`(1,)`，否则小括号会被理解为运算优先级。

- 方法很少：index()（找不到报错 ValueError）、count()（没有返回 0）、len()
- 不可修改：增删改元素都会报错
- 例外：元组内的 list 元素的内容可以改（元组存的是列表的引用地址，地址没变就不算修改元组），但不能把这个 list 替换成别的对象
- 适用：封装不希望被篡改的数据

### str 字符串（再认识）

字符串是字符的容器：支持下标索引、不可修改、允许重复、支持遍历，元素只能是字符。

常用操作：

| 操作 | 说明 |
|---|---|
| 字符串[下标] | 取出特定位置字符 |
| 字符串.index(子串) | 查找子串第一个匹配项的下标，找不到报错 |
| 字符串.replace(旧, 新) | 全部替换，**返回新字符串**，原串不变 |
| 字符串.split(分隔符) | 按分隔符切分，**返回列表**（不含分隔符本身） |
| 字符串.strip() | 去掉首尾所有空格和换行符（中间不动） |
| 字符串.strip(子串) | 去掉首尾指定字符——**按单个字符逐个去除**，不是整体匹配 |
| 字符串.count(子串) | 统计出现次数，没有返回 0 |
| 字符串.find(子串) | 第一次出现的下标，找不到返回 -1（不报错） |
| 字符串.rfind(子串) | 从右往左找，但下标仍从左往右数 |
| 分隔符.join(容器) | 用分隔符把元素拼接成字符串，如 `",".join("你好啊")` → `你,好,啊` |
| 字符串.upper() / lower() | 全转大写 / 小写 |
| len(字符串) | 字符个数；数字、字母、符号、中文都算 1 个字符 |

### 序列与切片

序列指内容连续、有序、可使用下标索引的一类容器：**list、tuple、str 都是序列**。

切片：从序列中取出一个子序列，**不影响原序列，返回新序列**。

```python
序列[起始下标:结束下标:步长]
```

- 起始下标留空：从头开始；结束下标留空：截取到结尾（结束下标本身不含）
- 步长默认 1；步长 N 表示每次跳过 N-1 个元素
- 步长为负数表示反向取，此时起始/结束下标也要按反向理解
- `序列[::-1]` 是经典的反转写法

### set 集合

定义：`{元素1, 元素2}`、空集合只能 `set()`（`{}` 是空字典！）。

特点：自动去重、无序（不支持下标索引，不能用 while 遍历）、可修改、元素必须可 hash（不能存 list、dict、set，可以存 tuple）；True/False 会被识别为 1/0 参与去重。

常用方法：

| 操作 | 说明 |
|---|---|
| 集合.add(元素) | 添加元素，重复则添加无效 |
| 集合.remove(元素) | 移除指定元素，不存在报错 KeyError |
| 集合.pop() | 随机取出一个元素并返回，集合被修改 |
| 集合.clear() | 清空集合 |
| 集合1.difference(集合2) | 返回差集新集合（1 有 2 没有），原集合不变 |
| 集合1.difference_update(集合2) | 在集合1中删除与集合2相同的元素，返回 None，集合1被修改 |
| 集合1.union(集合2) | 合并去重，返回新集合，原集合不变 |
| len(集合) | 元素个数 |

### dict 字典

按 Key 检索 Value 的键值对容器，适合「通过姓名查成绩」这类场景。

定义：`{键1: 值1, 键2: 值2}`、`{}`、`dict()`。

规则：Key 唯一（重复定义会覆盖原值）、Value 可重复；Key 和 Value 可以是任意类型（Key 不可为字典）；不支持下标索引，用 `字典[Key]` 取值，Key 不存在会报错。

常用操作：

| 操作 | 说明 |
|---|---|
| 字典[Key] | 获取 Value |
| 字典[Key] = Value | Key 不存在即新增，存在即更新 |
| 字典.pop(Key) | 删除键值对，返回被删的 Value |
| 字典.clear() | 清空 |
| 字典.keys() | 全部 Key（可用于 for 遍历） |
| 字典.values() | 全部 Value |
| 字典.items() | 全部键值对对象，索引 0 是键、1 是值 |
| len(字典) | 键值对数量 |

支持嵌套：`字典["外层键"]["内层键"]` 或 `字典["键"][列表下标]` 逐级取值。

### 容器通用操作

| 功能 | 描述 |
|---|---|
| for 循环 | 遍历容器（字典遍历的是 key） |
| len() | 元素个数 |
| max() / min() | 最大 / 最小元素（字符串按字符比较） |
| list() / tuple() / str() / set() | 容器类型互转 |
| sorted(容器, [reverse=True]) | 排序，**结果一律是 list**；reverse=True 降序；字典默认按 Key 排 |
| 容器 * n | 复制拼接 n 份（仅 list、tuple、str） |
| 容器1 + 容器2 | 同类型拼接（仅 list、tuple、str） |

## 重点与难点分析

- **append vs extend**：append 把参数当整体塞进去（`list1.append(list2)` 得到嵌套列表），extend 把容器拆开逐个追加（参数必须是可迭代容器，传 int 会报 `TypeError: 'int' object is not iterable`）。
- **可变 vs 不可变**是选型的核心：tuple 和 str 不可修改，replace、strip、切片等都是「返回新对象，原对象不变」；list、set、dict 可原地修改。用 id() 查看地址可以验证「重新赋值 ≠ 修改」。
- **空集合的陷阱**：`{}` 创建的是空字典，空集合必须写 `set()`。
- **strip(子串) 按字符去**：`"12hello...112".strip("12")` 去掉的是首尾的 '1' 和 '2' 字符，不是子串 "12" 整体。
- **pop 一族的返回值差异**：list.pop() 返回被删元素、set.pop() 随机返回元素、dict.pop(Key) 返回 Value——pop 总是有返回值的；而 remove、clear、insert、append 都返回 None。
- **切片的结束下标取不到**：`list1[1:4]` 拿到下标 1、2、3；与 range 的包左不包右一致。
- **字典 Key 不可重复**：重复赋值不是报错而是静默覆盖，新增与更新共用同一语法 `字典[Key] = Value`，靠 Key 是否已存在区分。
- **sorted 与字符串数字**：sorted 对容器排序后统一返回 list；字符串形式的数字按字符序排（'77' 排在 '12' 前面之类的意外），需要数值排序先转 int。

## 示例

列表定义与下标索引：

```python
# 定义列表
names = ["张三", '李四', '王五', '赵六', '周日', '周一']
# 下标索引从左往右：0,1,2...；从右往左：-1,-2...
print(names[2])   # 王五
print(names[0])   # 张三

# 嵌套列表逐级取值
names = ['zsf', 'ls', ['ww', 'zl', 'zs'], ['ln', 'gk', 'dn']]
print(names[2][2])  # zs
print(names[3][1])  # gk
```

这段演示什么：下标从 0 开始、嵌套列表用多级下标逐层定位；下标越界会报错。

append 与 extend 的区别：

```python
list1 = [1, 2, 3, 4]
list2 = [5, 6, 7, 8]
list1.append(list2)
print(list1)  # [1, 2, 3, 4, [5, 6, 7, 8]]，list2被当成一个整体元素

list3 = [1, 2, 3, 4]
list3.extend(list2)
print(list3)  # [1, 2, 3, 4, 5, 6, 7, 8]，list2被遍历后逐个追加
```

这段演示什么：append 整体追加 vs extend 拆散追加，是列表方法中最经典的辨析点。

列表的删除方法：

```python
list1 = [1, 2, 3, 4, 5, 6]
del list1[3]        # 删除下标3的元素
print(list1)        # [1, 2, 3, 5, 6]

num = list1.pop()   # 不写参数默认删最后一个，并把删除的元素返回
print(num)          # 6

list2 = ['张三', '李四', '王扁', '王五']
list2.remove('王五')  # 按元素值删除，无返回值；元素不存在会报错
print(list2)
list2.clear()         # 清空列表，返回 None
print(list2)          # []
```

这段演示什么：del / pop / remove / clear 四种删除手段的分工——按下标、按元素、清空，以及只有 pop 带回返回值。

元组的定义与「不可修改」边界：

```python
# 单元素元组必须加逗号，否则会被当成小括号优先级
tuple4 = (1,)
print(tuple4, type(tuple4))  # (1,) <class 'tuple'>

# 元组内容不可更改指的是元素本身；内部的list元素可以改
tuple1 = (1, 2, 3, [4, 5, 6])
tuple1[3][0] = '4'   # 修改元组内列表的元素：合法
print(tuple1)        # (1, 2, 3, ['4', 5, 6])
```

这段演示什么：单元素元组的逗号陷阱；「不可修改」锁定的是引用地址，不是引用指向的内容。

字符串常用操作：

```python
str1 = "python is a language"
# replace返回新字符串，原串不变
str1_replace = str1.replace('a', 'A')
print(str1_replace)

# split按分隔符切分，结果列表中不含分隔符
list1 = str1.split("a")
print(list1)

# strip去掉两端所有空格（中间不动）；strip("12")按字符逐个去
str2 = "12python 1is a language25112"
print(str2.strip("12"))

# join：用调用者作分隔符拼接
print(",".join("你好啊"))  # 你,好,啊
```

这段演示什么：字符串不可修改，所有操作都返回新对象；split 与 join 互为逆操作，常配合做格式转换。

切片：

```python
list1 = ['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h']
print(list1[::2])     # 从头开始，步长2：['a','c','e','g']
print(list1[1:6:2])   # 下标1到6(不含)，步长2：['b','d','f']

str1 = "abcd"
print(str1[::-1])     # 倒序：dcba —— 经典的字符串反转写法
```

这段演示什么：切片三要素（起始:结束:步长）的组合；步长为负即反向取值，结束下标永远取不到。

集合的去重与方法：

```python
# 自动去重、无序
set1 = {'a', 'a', 'b', 'c', 'b'}
print(set1, type(set1))  # 重复元素被去除

set1 = {1, 2, 3, 4}
set2 = {1, 5, 6, 7}
set3 = set1.difference(set2)   # {2, 3, 4}，新集合，原集合不变
set1.difference_update(set2)   # 无返回值，set1被修改为 {2, 3, 4}
set5 = set1.union(set2)        # 合并去重的新集合
```

这段演示什么：集合的三大特征（去重、无序、可修改）；difference 返回新集合而 difference_update 原地修改，后缀 _update 是「就地操作」的信号。

字典的定义、取值与遍历：

```python
dict1 = {"周杰伦": 77, "王力宏": 88, "林俊杰": 99, "王扁": 100}
print(dict1["王扁"])  # 100，Key不存在会报错

# 新增和更新共用语法，靠Key是否已存在区分
dict1["科比"] = 100    # 新增
dict1["周杰伦"] = 99   # 更新（覆盖）

# 嵌套字典逐级取值
dict2 = {
    "王力红": {"语文": 77, "数学": 66, "英语": 33},
    "周杰轮": {"语文": 88, "数学": 86, "英语": 55},
}
print(dict2["王力红"]["英语"])  # 33

# 三种遍历方式
for i in dict1.keys():      # 遍历键，再通过键取值
    print(f"键是：{i}，值是：{dict1[i]}")
for i in dict1.values():    # 直接遍历值
    print(i)
for i in dict1.items():     # 遍历键值对对象，i[0]是键，i[1]是值
    print(i[0], i[1])
```

这段演示什么：字典按 Key 检索 Value 的核心用法、新增/更新同语法、嵌套取值与三种遍历套路。

容器的通用操作：

```python
list1 = [5, 4, 77, 3, 12, 6]
tuple1 = (5, 4, 77, 3, 12, 6)
str1 = "1562345216789"
set1 = {5, 4, 77, 3, 12, 6}

print(max(list1), min(list1))      # 77 3
print(list(tuple1), list(set1), list(str1))  # 类型互转
print(sorted(list1))               # 排序后得到list
print(sorted(list1, reverse=True)) # 降序
print(list1 * 2)                   # 复制拼接，仅list/tuple/str支持
print(tuple1 + tuple1)             # 同类型拼接
```

这段演示什么：len/max/min/sorted/类型转换对五类容器通用；注意 sorted 无论输入什么都返回 list。
