# 分支判断语句

## 概念说明

程序默认按顺序从上到下执行，但现实中的逻辑往往需要「看情况办事」：密码正确才能取钱、余额够才能上车。判断语句（if / elif / else）让程序根据条件的真假走不同的分支，是程序三大基本结构（顺序、分支、循环）之一。配合 random 模块生成随机数，还能写出猜拳、猜数字这类带不确定性的交互程序。

## 技术点之间的联系

分支语句的条件来自上一篇的比较运算符与逻辑运算符（结果必须是 bool 值）；input 录入 + 类型转换 + if 判断是最常见的组合套路。嵌套 if 处理「先过第一道门、再过第二道门」的场景，而随机数模块 random 则为分支提供了不可预知的输入，是综合案例的关键拼图。

## 方法与实现要点

### if 基本格式

```python
if 条件:
    条件成立（条件为 True）时执行的内容
```

注意点：

- 条件后要跟冒号
- if 顶格写，条件成立时执行的内容换行并用 4 个空格（tab）缩进
- 缩进的代码块是一个整体：条件成立则都执行，不成立则都不执行

### if...else

```python
if 条件:
    条件成立时执行的内容
else:
    条件不成立时执行的内容
```

- if 和 else 同级别、都顶格写，二者只能执行一个（二选一）
- else 后也要跟冒号，else 不能独立于 if 存在

### if...elif...else

```python
if 条件1:
    条件1成立时执行的内容
elif 条件2:
    条件2成立时执行的内容
elif 条件3:
    条件3成立时执行的内容
else:
    以上所有条件都不成立时执行的内容
```

- if / elif / else 同级别顶格写；elif 可以有多个
- if 和 elif 后都要跟条件，条件和 else 后都要跟冒号
- elif 和 else 不能独立于 if 存在

### if 嵌套

```python
if 条件1:
    条件1满足时执行的内容
    if 条件2:
        满足条件1的前提下，满足条件2后执行的内容
    else:
        满足条件1但不满足条件2执行的内容
else:
    不满足条件1执行的内容
```

嵌套适用于「有前置条件」的场景，建议嵌套不要超过 3 层，否则影响可读性和执行效率。

### random 随机数

```python
import random                # 1. 先导入 random 库（建议顶格写）
num = random.randint(1, 10)  # 2. 生成 1-10 的随机整数，包左包右
```

`randint(x, y)` 有返回值，生成的随机数包含 x 和 y 两个端点（注意与 range 的「包左不包右」区分）。

## 重点与难点分析

- **缩进即归属**：if 下方缩进的代码块才是「条件成立时执行的内容」，与 if 对齐的代码不受条件控制、永远执行。用 tab 缩进了想退回上一级用 shift + tab。
- **input 的返回值是 str**：`palyer == "1"` 与 `palyer == 1` 完全是两回事，`"1" == 1` 恒为 False。判断前要明确：按字符串比就不转换，按数字比就先 int()。
- **elif 的顺序有意义**：条件是从上往下逐个判断的，一旦命中就不再判断后面的分支；范围重叠时，更严格的条件要写在前面。
- **else 是兜底**：所有条件都不成立时才进入 else，利用它可以做非法输入提示，增强代码健壮性（如先判断输入是否在 1-7 之间，再细分周几）。
- **randint 包两端、range 包左不包右**：`random.randint(1, 100)` 能取到 100，`range(1, 100)` 取不到 100，混淆二者是常见错误。
- **嵌套不如平铺时可考虑逻辑运算符**：能用 `a and b` 合并成一层判断的，就不必写两层嵌套；但「先验证验证码，再验证用户名密码」这类有先后顺序的场景，嵌套语义更清晰。

## 示例

if 基本用法（录入并转换一体化）：

```python
age = int(input("请输入您的年龄："))  # input录入 + int转换的合体写法
if age >= 18:  # 条件为True才会进入判断体
    print(f"我已经{age}岁了，已经成年了，可以去网咖了！！！")
print("您还未成年，请回去好好学习天天向上！！！")  # 顶格代码不受if控制，永远执行
```

这段演示什么：if 的基本格式与缩进规则；最后一行不缩进，无论条件成立与否都会执行。

if...elif...else 多分支：

```python
# 需求:判断一年4季节，1-3月春季，4-6月夏季，7-9月秋季，10-12月冬季
month = int(input("请输入您要判断的月份："))
if month >= 1 and month <= 3:
    print(f"您要判断的是{month}月，该月属于春季")
elif month >= 4 and month <= 6:
    print(f"您要判断的是{month}月，该月属于夏季")
elif month >= 7 and month <= 9:
    print(f"您要判断的是{month}月，该月属于秋季")
elif month >= 10 and month <= 12:
    print(f"您要判断的是{month}月，该月属于冬季")
else:
    print(f"您输入的是{month}月,该月不存在，请重新输入！")
```

这段演示什么：elif 可以有多个，条件配合 and 划定区间，else 兜底处理非法输入。

if 嵌套（先上车，再找座）：

```python
# 需求：公交卡余额超过2元可以上车；车上有空位才可以坐下
balance = int(input("请输入您的公交卡余额："))
if balance > 2:
    # 余额足够，进入第二层判断：是否有空座位
    empty_seat = input("请输入是空/非空：")
    if "空" == empty_seat:
        print(f"您的公交卡余额是：{balance}元，车上有空位置，赶紧坐好，马上开车了！")
    else:
        print(f"您的公交卡余额是：{balance}元，车上已经坐满人了，请站稳扶好！")
else:
    print(f"您的余额是：{balance}元，请尽快充值~")
```

这段演示什么：嵌套 if 表达「先决条件」——只有通过外层判断（余额够），内层判断（有无座位）才有意义。

外层校验 + 内层细分的健壮性写法：

```python
# 需求：输入1-7数字代表周一到周日；先校验范围再细分，增强健壮性
number = int(input("请输入您要判断的日期："))
if number >= 1 and number <= 7:  # 先拦截非法输入
    if 1 == number:
        print(f"您输入的数字是{number},今天是周一")
    elif 2 == number:
        print(f"您输入的数字是{number},今天是周二")
    elif 3 == number:
        print(f"您输入的数字是{number},今天是周三")
    elif 4 == number:
        print(f"您输入的数字是{number},今天是周四")
    elif 5 == number:
        print(f"您输入的数字是{number},今天是周五")
    else:
        print(f"您输入的数字是{number},今天是周末")
else:
    print(f"您输入的是{number},请输入1-7之间的数字！")
```

这段演示什么：把合法性校验放在外层，是实际开发中保护内部逻辑的常用手法。

综合案例：剪刀石头布（人机对战）：

```python
"""
规则：石头：1   剪刀：2    布：3
玩家胜利的条件：
    玩家出石头(1)且电脑出剪刀(2)
    玩家出剪刀(2)且电脑出布(3)
    玩家出布(3)且电脑出石头(1)
"""
import random

# 玩家键盘录入；因为按字符串对比，所以不需要转换成int类型
palyer = input("请输入您要出的拳(石头：1，剪刀：2，布：3)：")
# 电脑随机出拳，范围1-3
computer = random.randint(1, 3)

if palyer == "1" or palyer == "2" or palyer == "3":  # 先判断输入是否合法
    if (palyer == "1" and computer == 2) or (palyer == "2" and computer == 3) or (palyer == "3" and computer == 1):
        print("恭喜玩家胜利了！！！")
    # 排除玩家胜的三种情况后，先判平局（代码最简单），剩下就是电脑胜
    elif int(palyer) == computer:
        print("两家打平了，以和为贵！！！")
    else:
        print("恭喜电脑胜利了！！！")
else:
    print("您的输入有误，请输入1-3数字！！")
```

这段演示什么：分支结构的综合应用——input 合法性校验、random 生成对手、or 组合胜利条件、利用排除法安排 if/elif/else 的判断顺序。
