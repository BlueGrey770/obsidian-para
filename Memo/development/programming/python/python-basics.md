# Python 基础语法

## 概念说明

本篇覆盖写 Python 程序最先要掌握的四件事：注释（给代码写说明）、变量（临时存储数据）、数据类型（数据长什么样）、标识符命名（给变量起名字的规矩），以及 print 输出（把结果展示出来）。它们是后续所有语法——输入、运算符、判断、循环——的共同地基。

## 技术点之间的联系

变量是数据的容器，数据类型描述容器里装的是什么；注释和命名规范让代码可读；print 则是观察程序运行结果的第一个窗口。下一篇的 input 负责「进」，本篇的 print 负责「出」，二者配合类型转换就构成了最基本的交互闭环。

## 方法与实现要点

### 注释

注释是对代码进行解释说明的文字，不参与解释器解析，能大大增强程序的可读性。一般放在代码的上方或右侧。

| 分类 | 写法 | 说明 |
|---|---|---|
| 单行注释 | `# 注释内容` | 最常用，快捷键 ctrl + /（添加/取消同一快捷键） |
| 多行注释 | `""" 注释内容 """` | 三引号包裹，常用于函数说明文档 |

### 变量与数据类型

- 变量是**临时存储数据的容器**，在程序运行过程中值可以发生改变
- 定义格式：`变量名 = 变量值`——永远是等号右侧的值赋给等号左侧的变量，`=` 两边各保留一个空格
- 查看变量类型：`type(变量名)`，该函数有返回值，需用变量接收或直接 print

基本数据类型：

| 类型 | 说明 | 示例 |
|---|---|---|
| int | 整型，存放整数 | -1, 10, 0 |
| float | 浮点型，存放小数 | -3.14, 6.66 |
| bool | 布尔类型，表示成立或不成立 | True / False |
| str | 字符串类型，引号引起来的数据 | "abc"、'abc'、"""abc""" |

布尔类型补充：除 True 和 False 外，0 可表示假，任何非 0 数据都表示真（非 0 即为真）。字符串用单引号、双引号、三引号都可以；需要保留换行和缩进的多行文本（如一首诗）用三引号。

### 标识符与关键字

标识符是开发人员在程序中自定义的名称（变量名、函数名、类名等）。

命名规则（必须遵守）：

1. 见名知意
2. 只能由数字、字母、下划线组成，且数字不能开头
3. 区分大小写（`name` 和 `Name` 是两个变量）
4. 不能与关键字重名；查看关键字：`import keyword` 后 `print(keyword.kwlist)`

命名规范（建议遵守）：

| 规范 | 特点 | 适用 | 示例 |
|---|---|---|---|
| 小驼峰 | 第一个单词首字母小写，其余单词首字母大写 | 变量名、函数名 | myName、getMax |
| 大驼峰 | 所有单词首字母大写 | 类名 | FirstName |
| 下划线 | 单词间用下划线连接 | 变量名、函数名 | my_name |

### print 输出

- `print(内容)` 默认自带换行；取消换行用 `print("内容", end="")`，end 参数的值就是每次输出后追加的结尾
- 转义字符：`\n` 换行符、`\t` 制表符（对齐多行内容用）
- 输出多个值：`print("我今年", age, "岁了")`，逗号分隔即可

格式化输出有两种方式：

**方式一：占位符**

| 格式符号 | 转化 |
|---|---|
| %s | 字符串（string） |
| %d | 整型（int） |
| %f | 浮点型（float），默认 6 位小数，`%.2f` 保留 2 位并四舍五入 |

写法：`print("我的姓名是%s, 年龄是%d" % (name, age))`。补零技巧：`%06d` 输出 6 位整数、不足补零（如学号 000001）；输出百分号本身用 `%%`。

**方式二：f-string（以后常用）**

`print(f"{变量名}")`——不需要关心占位符类型，大括号里还能直接写运算表达式；保留小数为 `f"{变量:.2f}"`，同样四舍五入。

## 重点与难点分析

- **赋值方向不可颠倒**：看到 `=` 就认定右侧是值、左侧是变量，`num1 + num2 = result` 是错误写法。
- **变量名加引号就成了字符串**：`print("name")` 输出的是字符串常量 name，不是变量的值。
- **%f 的默认 6 位小数**是常见困惑来源，需要指定位数时写 `%.2f`；浮点运算在 f-string 大括号内可能产生精度损失，遇到 float 结果建议保留小数位输出。
- **手机号等长数字建议用字符串存储**：int 类型有长度限制的概念误区要避开——实际上更关键的是手机号可能以 0 开头或需要按字符处理，字符串更安全。
- **区分大小写**是新手最容易忽略的规则，`Name` 和 `name` 互不相干。

## 示例

变量的定义与重新赋值：

```python
# 定义两个变量，用来存储姓名和年龄
name = '张三'
age = 18

name = '王五'
age = age + 15
# print("name") 注意，此时name是字符串类型的常量值，而不是name变量
print(name)
print(age)
```

这段演示什么：变量先定义后使用，可以随时被重新赋值；`age + 15` 的结果再存回 `age`，体现「运行过程中值可变」。

用 type() 查看四种基本类型：

```python
age = 18
print(type(age))        # <class 'int'>

height = 1.80
print(type(height))     # <class 'float'>

sex = True
print(type(sex))        # <class 'bool'>

name1 = '张三'
name2 = "李四"
name3 = """王五"""
print(type(name1), type(name2), type(name3))  # 均为 str
```

这段演示什么：type() 返回变量的类型；三种引号写出的都是 str，类型上没有区别。

标识符区分大小写：

```python
# 如果两次打印都是李四，代表不区分大小写；如果两次打印不同，代表区分大小写
# 结论：区分大小写
name = '张三'
Name = '李四'
print(name)
print(Name)
```

这段演示什么：name 与 Name 是两个独立的变量，验证标识符区分大小写。

print 的换行控制：

```python
# 如果想让12一行，34一行
print("12\n34")

# 使用end参数来取消print默认换行
print("我爱", end=',')
print("中国")
```

这段演示什么：`\n` 在字符串内部换行；end 参数替换掉 print 默认的换行结尾，两次输出可拼在同一行。

占位符格式化输出：

```python
age = 18
name = '张三'
sex = '男'
height = 1.86
print("我叫：%s，我的年龄是：%d，我的性别是：%s，我的身高是：%.2f 米" % (name, age, sex, height))
```

这段演示什么：% 占位符按顺序与括号内的变量一一对应，`%.2f` 把身高格式化为两位小数。

f-string 格式化输出：

```python
price = 9.0
weight = 5
money = price * weight
print(f"榴莲单价 {price} 元／斤，购买了 {weight} 斤，需要支付 {money:.2f} 元")
```

这段演示什么：f-string 直接在字符串里嵌入变量和表达式，`{money:.2f}` 控制小数位，无需关心类型匹配。
