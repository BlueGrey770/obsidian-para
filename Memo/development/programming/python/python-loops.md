# 循环语句

## 概念说明

当一段代码需要重复执行多次时，就该用循环。循环与判断一样，是程序最基础最核心的逻辑功能——轮播图、批量处理、持续监控背后都是循环。Python 提供两种循环：while（按条件循环）和 for（按容器轮询），配合 break / continue 可以中途跳出或跳过，嵌套循环则能处理行列式的二维结构（如九九乘法表）。

## 技术点之间的联系

循环条件是上一篇比较/逻辑运算符的延续；循环体内几乎必然用到累加、计数等复合赋值运算。for 循环遍历的「待处理数据集」在数据容器一篇会全面展开（列表、元组、字符串、集合、字典都是可迭代对象），而循环与 if 的组合（循环里做判断）是后续所有实战案例的基本骨架。

## 方法与实现要点

### while 循环

```python
# 定义初始化变量用来条件控制
变量名 = 初始化值
while 条件:
    条件成立时循环执行的内容
    控制条件语句（修改变量的值，如 变量名 += 1）
```

注意点：

- 条件的结果是 bool 类型：True 继续循环，False 结束循环
- 必须规划好终止条件，否则就是死循环（条件恒成立）
- 初始化变量、循环体、控制条件语句，三者缺一不可

### for 循环

```python
for 临时变量 in 待处理数据集（可迭代对象）:
    循环体
```

- for 是一种「轮询」机制：从数据集中逐个取出数据，赋值给临时变量进行处理
- in 判断临时变量的值是否在容器内：在则继续循环，取完了（返回 False）循环结束
- for 无法自定义循环条件，理论上不能构建无限循环（被处理的数据集不可能无限大）

### range 数字序列

for 循环本质是遍历可迭代对象，range 用于快速获得一个数字序列：

| 语法 | 说明 | 示例 |
|---|---|---|
| range(num) | 从 0 到 num-1 | range(5) → 0,1,2,3,4 |
| range(num1, num2) | 从 num1 到 num2-1 | range(5, 10) → 5,6,7,8,9 |
| range(num1, num2, step) | 同上，步长为 step | range(5, 10, 2) → 5,7,9 |

**包左不包右**：结束值永远取不到。与 `random.randint(x, y)`（包左包右）正好相反。

### while 与 for 的对比

| 维度 | while | for |
|---|---|---|
| 循环控制 | 自定义条件，自行控制 | 不可自定义条件，只能从容器中逐个取出 |
| 无限循环 | 可以做到（while True） | 理论上不可以（容器容量有限） |
| 适用场景 | 任何想循环的场景，尤其循环次数未知（需要计算才知道） | 遍历数据容器，或一眼能看出次数的固定循环 |

### 循环嵌套

```python
for 临时变量1 in 容器1:
    for 临时变量2 in 容器2:
        循环体
```

- 外层循环 1 次，内层循环 N 次（N 为内层循环次数）
- 经典口诀：**外层控制行，内层控制列**
- 不建议嵌套超过 3 层（效率与可读性问题，非强制）

### break 与 continue

| 关键字 | 作用 |
|---|---|
| continue | 中断本次循环，直接进入下一次 |
| break | 直接结束所在的循环 |

注意：

- 二者在 for 和 while 中作用一致
- 嵌套循环中只能作用于**所在的这一层**，无法影响上层循环
- 一般写在循环体有效代码的最后一行；其后同级别不要再写代码

### 累加与计数思维模式

循环里最常用的两种套路：

- **累加**：循环外定义 `sum = 0`，循环内 `sum += 当前值`
- **计数**：循环外定义 `count = 0`，循环内满足条件时 `count += 1`

### for 循环的变量作用域

临时变量的作用域按编程规范只限定在 for 循环内部。实际上在循环外也能访问到（是规范限定而非强制限定），但不建议这么做；确实需要在循环外使用时，应在循环外预先定义该变量。

## 重点与难点分析

- **忘记控制条件是死循环的第一成因**：`while num <= 100:` 体内如果没有 `num += 1`，程序永不结束。
- **range 的边界错觉**：`range(1, 100)` 只能加到 99，求 1-100 的累加和必须写 `range(1, 101)`。
- **九九乘法表的内层边界**：内层循环的列数取决于当前行号（`j <= i` 或 `range(1, i+1)`），这是「外层行、内层列」思想的直接体现；print 用 `end="\t"` 不换行对齐，内层结束后空 `print()` 换行。
- **break/continue 只作用本层**：嵌套循环里内层的 break 跳不出外层；需要整体退出时，常见做法是把外层设为 `while True` 并在内层设置标志位，或改用函数 return。
- **while True + break 是「次数未知」的标准解法**：猜数字这类「直到猜中为止」的需求，终止条件不适合用计数，就用条件恒真 + 猜中时 break。
- **while 遍历容器要靠索引**：`while idx < len(容器)` 配合 `容器[idx]`；for 直接拿到元素，遍历场景优先 for。

## 示例

while 基本格式与累加思维（1-100 求和）：

```python
# 1.先定义控制条件的变量
num = 1
# sum是用来存储1-100的累加和结果的
sum = 0
while num <= 100:
    # 2.累加：sum = sum + num
    sum += num
    # 条件控制语句，没有它就是死循环
    num += 1
print(f"1-100的累加和的计算结果是：{sum}")  # 5050
```

这段演示什么：while 三要素（初始化变量、条件、控制语句）与「循环外定义、循环内累加」的经典模式。

while + if 组合（奇偶数分别求和）：

```python
num = 1
odd = 0   # 奇数和
even = 0  # 偶数和
while num <= 100:
    # 什么是奇数：num % 2 == 1；什么是偶数：num % 2 == 0
    if num % 2 == 0:
        even += num
    else:
        odd += num
    num += 1
print(f"1-100的奇数和是：{odd}，偶数和是：{even}")  # 奇数:2500, 偶数:2550
```

这段演示什么：循环体内嵌 if，用 % 取余做奇偶分流，两个累加器并行统计。

while True + break（猜数字游戏）：

```python
import random
num = random.randint(1, 100)
count = 0  # 统计猜测次数
# 循环次数未知（猜到为止），所以用 while True
while True:
    guess_num = int(input("请输入您要猜的数字："))
    count += 1
    if guess_num >= 1 and guess_num <= 100:
        if guess_num > num:
            print("您猜大了，请往小猜！")
        elif guess_num < num:
            print("您猜小了，请往大猜！")
        else:
            print("猜对了！")
            break  # 猜中，终止循环
    else:
        print("您输入的不在1-100范围内")
print(f"您一共猜了{count}次")
```

这段演示什么：while True 处理「终止时机未知」的循环；if/elif/else 给出方向提示，break 在达成条件时退出。

while 嵌套打印九九乘法表：

```python
# 外层循环控制行，内层循环控制列
num1 = 1
while num1 <= 9:
    num2 = 1
    while num2 <= num1:  # 列数最大值与行数相等
        print(f"{num2}*{num1}={num1*num2}", end="\t")  # end="\t"让内层内容在同一行
        num2 += 1
    # 内层执行完后换行
    print()
    num1 += 1
```

这段演示什么：嵌套循环的行列模型；`end="\t"` 制表符对齐、内层结束后空 print() 换行，是打印二维表格的固定技巧。

for 循环嵌套版九九乘法表：

```python
for i in range(1, 10):      # 9行
    # 因为i控制行，列数最大等于行数；range取不到i本身，所以+1
    for j in range(1, i + 1):
        print(f"{j} * {i} = {i*j}", end="\t")
    print()
```

这段演示什么：同一需求的 for 实现——无需手动初始化变量和控制条件，代码更紧凑；`range(1, i+1)` 体现包左不包右。

for 遍历字符串 + 计数思维：

```python
# 统计键盘录入的字符串中a有几个
content = input("请输入您要查看的字符串内容：")
sum = 0
for i in content:
    if i == "a":
        sum += 1
print(f"该输入的内容中有{sum}个a字符！")
```

这段演示什么：for 逐个取出字符（遍历），配合 if 与计数器完成统计——「遍历 + 判断 + 计数」三板斧。

break 与 continue 对比：

```python
# continue：吃到第3个苹果时发现是坏的，扔了，继续吃第4、5个
for i in range(1, 6):
    if i == 3:
        continue  # 跳过本次，进入下一次
    else:
        print(f"您吃了第{i}个苹果了！")

# break：吃完第3个就饱了，后面不再吃了
for i in range(1, 6):
    if i > 3:
        break  # 直接结束本层循环
    else:
        print(f"您吃了第{i}个苹果了！")
```

这段演示什么：continue 只跳过当次（输出 1、2、4、5），break 直接终结循环（输出 1、2、3），二者都只影响所在的那一层循环。
