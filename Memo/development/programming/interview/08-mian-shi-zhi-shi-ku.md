# 08 面试知识库

> 聚合自全部 Blog 题解、面试题库与每日背诵清单，按考察方向组织；已剔除个人求职相关内容。

## 一、Java 基础八股

- == 与 equals 的区别
- 接口和抽象类的区别；接口为什么不能有构造函数
- 重写和重载的区别
- 面向对象的三大特征
- String / StringBuffer / StringBuilder 的区别；String 类的常用方法
- Array 与 ArrayList 的区别；数组和链表结构的特点
- lambda 和匿名内部类的区别
- 单列集合的分类；hash 表存储数据的原理；并发修改异常的原因
- JVM 内存结构；类加载器的加载过程
- 反射机制及主要用到的方法
- sleep 和 wait 的区别
- 悲观锁和乐观锁的区别

## 二、框架八股（Spring / MyBatis）

- Spring MVC 执行原理；Spring MVC 解决的核心问题
- 元注解有哪些；Http 协议的组成部分
- IoC 和 DI 是什么；Spring 框架解决了哪些问题
- Spring 中 Bean 的几种注入方式
- 介绍一下 AOP；Spring Boot 自动配置的原理
- 拦截器和过滤器的区别
- MyBatis 的参数处理情况、XML 配置规则、动态 SQL 标签及作用、一对多注意事项
- MyBatis-Plus 的实现原理
- 事务的四大特性
- 第三方 Bean 管理的相关注解；Bean 冲突的解决方案

## 三、数据库八股

- MySQL 分组的注意事项、分页语法
- 什么是 SQL 注入以及如何避免
- MySQL 索引的三大分类角度
- ShardingSphere（Sharding-JDBC）分库分表讲解

## 四、微服务与中间件八股

- 项目为什么采用微服务架构（通用回答思路）
- Spring Boot 和 Spring Cloud 的理解与区别
- Java 远程调用技术有哪些
- Nginx 负载均衡；反向代理为什么叫"反向"
- 服务注册与发现流程；OpenFeign 的工作原理
- Seata 四大分布式事务模式对比
- MQ：应用场景、工作模型、消息可靠性、延迟消息、消息堆积处理、集群模式
- 缓存：一致性、穿透、击穿、雪崩
- Redis：五种数据结构命令、持久化（RDB/AOF）、主从 / 哨兵 / 分片集群
- Elasticsearch：查询相关操作、索引同步方案

## 五、设计模式与底层原理

- 策略模式深度解析：核心定义、实现流程（以支付场景为例）、Spring 环境下的实战、适用场景、框架中的典型应用
- Spring 核心设计模式及使用场景
- Spring IoC 容器底层如何用 ConcurrentHashMap 存储 Bean
- JDK 动态代理与 CGLIB 字节码生成技术对比
- 构建者（Builder）设计模式
- volatile 关键字

## 六、AI 方向面试题

- 大模型基础知识
- RAG 系统原理与优化（检索、评估）
- 智能体中台与场景题
- 神经网络基础
- 前沿技术动态
- 非技术类问题应对

## 七、工程规范（通用版）

- 表与字段命名规范（小写下划线、业务含义、主外键 / 布尔 / 时间字段命名约定）
- 字段设计规范（类型选择、约束使用）
- 接口与代码组织规范（三层架构、DTO/VO 的字段类型一致性）
