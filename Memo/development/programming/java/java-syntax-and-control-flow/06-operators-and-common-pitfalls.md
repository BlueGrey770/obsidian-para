# Java 运算符精讲与常见坑

## 一、概念说明

运算符分为六类：算术运算符、赋值运算符、关系运算符（比较运算符）、逻辑运算符、三元运算符（三目运算符）、位运算符。本篇覆盖前五类。

### 1. 算术运算符

| 符号 | 作用 | 说明 |
| --- | --- | --- |
| `+` | 加 | 基本数学加法 |
| `-` | 减 | 基本数学减法 |
| `*` | 乘 | 与"×"相同 |
| `/` | 除 | 与"÷"相同；**两个整数相除结果还是整数** |
| `%` | 取余（取模） | 获取两个数据做除法的余数，能整除则余 0 |

`/ %` 的分工：`10 / 3 = 3` 取商，`10 % 3 = 1` 取余。二者配合可以拆分整数的各位数字。

### 2. `+` 的连接符身份

`+` 与字符串做运算时变成连接符，结果依然是字符串。识别技巧一句话：**能算则算，不能算就连接在一起**。

### 3. 自增自减运算符

`++`、`--` 对变量自身的值加 1、减 1，只能操作变量，不能操作字面量。放在变量前后都合法，但含义不同。

### 4. 赋值运算符

基本赋值运算符是 `=`，从右往左看。扩展赋值运算符 `+=`、`-=`、`*=`、`/=`、`%=` 实现"运算后赋值"，例如 `a += b` 表示把 `a + b` 的结果存回 `a`。

### 5. 关系运算符与三元运算符

关系运算符 `>`、`>=`、`<`、`<=`、`==`、`!=` 判断数据是否满足条件，返回布尔值。三元运算符 `条件表达式 ? 值1 : 值2`：条件为 true 取值 1，为 false 取值 2。

### 6. 逻辑运算符

| 符号 | 叫法 | 运算逻辑 |
| --- | --- | --- |
| `&` | 逻辑与 | 全 true 才 true；无论左边结果如何右边都执行 |
| `\|` | 逻辑或 | 有 true 即 true；无论左边结果右边都执行 |
| `!` | 逻辑非 | 取反 |
| `^` | 逻辑异或 | 前后相同返回 false，不同返回 true |
| `&&` | 短路与 | 左边为 false，右边不执行 |
| `\|\|` | 短路或 | 左边为 true，右边不执行 |

## 二、技术点之间的联系

- 算术运算符负责"算出结果"，关系运算符负责"判断真假"，逻辑运算符负责"把多个真假条件组合起来"，三元运算符把"判断 + 二选一取值"压缩成一行——四者层层递进，构成流程控制的表达式基础。
- `/` 和 `%` 是孪生兄弟：一个取商（去掉低位），一个取余（留下低位），数值拆分、奇偶判断、水仙花数等经典题目都靠这对组合。
- 扩展赋值运算符与强制类型转换直接相关：`a += b` 的底层形式是 `a = (a的类型)(a + b)`，自带强转，这是它与 `a = a + b` 的本质差异。
- 自增自减的前后位置问题，本质是"取值时机"问题，它和 Java 表达式从左到右的求值顺序绑定，也是面试和笔试的常见考点。
- 关系运算符产出布尔值，布尔值正好是逻辑运算符、if 分支、三元运算符的输入——这条数据通路决定了"比较必须发生在条件组合之前"。

## 三、方法与实现要点

### 1. 整数除法与取余

```java
System.out.println(10 / 3);   // 3：两个整数相除结果还是整数
System.out.println(10 % 3);   // 1：取余数
```

想要小数结果，必须让小数参与运算（如 `5 / 2.0`），因为表达式结果类型由最高类型决定。

### 2. `+` 的运算与连接识别

```java
System.out.println("hello " + 100 + 'b');   // hello 100b：先遇到字符串，后面全是连接
System.out.println(100 + 'b' + " world");   // 198world：先算 100 + 98（'b' 的编码），再连接
```

从左到右执行：先以数值类型运算，遇到字符串才开始拼接。

### 3. 自增自减的前后区别

单独使用时（独占一行），放前放后没有区别：

```java
int a = 10;
++a;   // 或 a++，效果一样，a 变成 11
```

放在表达式中则有明显区别——放前面先自增/自减再取值，放后面先取值再自增/自减：

```java
int a = 20;
int rs1 = a++;   // rs1 = 20，之后 a = 21
int rs2 = a--;   // rs2 = 21，之后 a = 20
int rs3 = ++a;   // a = 21，rs3 = 21
int rs4 = --a;   // a = 20，rs4 = 20
```

### 4. 扩展赋值运算符的隐式强转

```java
int a = 10;
double b = 12.3;
a += b;                  // 编译通过，a = 22
// 底层等价于：a = (int)(a + b);
```

`a += b` 能编译而 `a = a + b` 不能（int 与 double 运算结果是 double，赋不回 int），差别就在于扩展赋值运算符隐含了强制类型转换。

### 5. 逻辑运算符的短路

```java
int a = 5;
System.out.println(a > 3 && a++ < 10);  // true，且 a 变成 6
System.out.println(a > 3 || a++ < 10);  // true，左边为 true 右边不执行，a 仍为 6
```

实际开发中常用 `&&`、`||`、`!`，既因为短路效率高，也因为它能避免无意义的右侧执行（右侧含运算时尤其要注意副作用是否发生）。

### 6. 三元运算符

```java
// 找出 a、b 的较小值，再和 c 比，得到三个数的最小值
int min = (a < b ? a : b) < c ? (a < b ? a : b) : c;
```

## 四、重点与难点分析

### 重点 1：`/` 的整数截断

`5 / 2` 结果是 `2` 不是 `2.5`——因为最高类型是整数。想让结果是 2.5，把接收变量改成 `double` 还不够（`double i = 5 / 2;` 依然输出 2.0，因为右侧已经按整数算完），必须让参与运算的数据中有小数：`5 / 2.0`。

### 重点 2：`==` 与 `=` 的书写

判断是否相等一定是 `==`，误写成 `=` 就变成赋值语句。在 if 条件里写错会直接改变程序逻辑甚至编译报错。

### 难点 1：自增自减混合表达式

面对 `int rs = c++ + ++c - --d - ++d + 1 + c--;` 这类题目，方法是从左到右逐项拆解，每遇到一个 `++/--` 就立刻更新该变量的当前值，并区分"取值"发生在自增前还是自增后。笔试爱考、工程禁用——真实代码里一个表达式最多出现一次自增自减。

### 难点 2：`+=` 隐含强转的双刃剑

`a += b` 的隐式强转让代码简洁，但也会悄悄丢精度（如上例中 22.3 被截成 22）。笔试题常拿"为什么 `a += b` 不报错而 `a = a + b` 报错"来考这个机制。

### 难点 3：`^` 异或的真值表

异或是"相同为 false、不同为 true"，与直觉的"或"相反，容易记反。记法：异或异或，**有异才为真**。

### 易错点清单

- `++`、`--` 不能操作字面量（`5++` 报错）；
- 除法想得到小数，必须有小数参与运算，只改接收类型无效；
- `&`、`|` 不短路，右边一定会执行，含副作用的表达式要警惕；
- 三元运算符嵌套可读性差，超过两层建议改 if-else。

## 五、示例

### 示例 1：镜子数判断（算术 + 关系 + 三元综合）

需求：键盘录入一个四位数，判断是否为镜子数（对称数，如 1221）。

```java
public static void demo13() {
    Scanner sc = new Scanner(System.in);
    int a = sc.nextInt();
    // 拆出个、十、百、千位
    int ge = a % 10;
    int shi = a / 10 % 10;
    int bai = a / 100 % 10;
    int qian = a / 1000;
    // 个位与千位相等、十位与百位相等，即是对称数
    String result = ge == qian && bai == shi ? a + "是镜子数" : a + "不是镜子数";
    System.out.println(result);
}
```

### 示例 2：三个数求最小值（三元运算符嵌套）

```java
// 先找出 a 和 b 的较小值，再与 c 比较
int smaller = a < b ? a : b;
int result = smaller < c ? smaller : c;
// 一行写法（可读性差，仅演示）：
// int result = a < b ? (a < c ? a : c) : (b < c ? b : c);
```

### 示例 3：赋值运算符的累加本质

```java
int b = 10;
b = b + 5;   // 普通写法
b += 5;      // 等价写法：取出左右两边数据做加法，结果存回左边容器

int c = 0;
c = c + 1;
c += 1;
c++;         // 三种 +1 写法效果相同
```

### 示例 4：逻辑运算符判断区间

```java
int a = 5;
// 数学里的 3 < a < 10 在 Java 中必须拆开用逻辑与连接
System.out.println(a > 3 & a < 10);    // true
System.out.println(a > 3 && a < 10);   // true，且带短路效果
```

### 示例 5：密码校验（关系 + 三元）

需求：键盘录入用户密码，密码为 111111 输出"密码正确"，否则输出"密码有误"。

```java
public static void main(String[] args) {
    System.out.println("请输入密码：");
    Scanner sc = new Scanner(System.in);
    int a = sc.nextInt();
    estimatePassword(a);
}

public static void estimatePassword(int a){
    String estimate = a == 111111 ? "密码正确" : "密码有误";
    System.out.println(estimate);
}
```

### 示例 6：`+=` 隐藏强转的观察

```java
int a = 10;
double b = 12.3;
a += b;
System.out.println(a);   // 22
// 运算过程：a += b 等同于 a = (int)(a + b)，
// 因为要赋值给 int 变量 a，最终结果按 a 的类型截断
```
