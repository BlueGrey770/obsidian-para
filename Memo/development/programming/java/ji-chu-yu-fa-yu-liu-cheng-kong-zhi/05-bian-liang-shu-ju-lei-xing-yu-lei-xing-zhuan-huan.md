# Java 变量、数据类型与类型转换精讲

## 一、概念说明

### 1. 注释：只活在源码阶段的文字

注释是写在程序中对代码进行解释说明的文字，方便自己和他人理解程序。Java 有三种写法：

- 单行注释 `// 注释内容`：只需要注释一行时使用；
- 多行注释 `/* ... */`：需要注释多行时使用；
- 文档注释 `/** ... */`：一般用在类、方法、成员变量上，内容可以被 `javadoc` 提取到程序说明文档中。

注释的核心特点是**不影响程序执行**——编译后的 class 文件中已经没有注释了。可用 `javadoc -d 文件夹 -encoding 编码 程序名.java` 把文档注释导出成说明文档。

### 2. 字面量：程序中能直接书写的数据

学字面量的重点是搞清楚各种数据在程序中的书写格式：

| 数据 | 程序中的写法 | 说明 |
| --- | --- | --- |
| 整数 | `666`、`-88` | 与数学写法一致 |
| 小数 | `13.14`、`-5.21` | 与数学写法一致 |
| 字符 | `'A'`、`'0'`、`'我'` | 必须单引号，有且仅能一个字符 |
| 字符串 | `"HelloWorld"` | 必须双引号，内容可有可无 |
| 布尔值 | `true`、`false` | 只有两个值 |
| 空值 | `null` | 特殊值，表示"什么都没有" |
| 特殊字符 | `'\t'`、`'\n'` | 制表符、换行符 |

### 3. 变量：内存中的一块存储区域

变量是内存中的一块区域，可以理解成一个盒子，用来装程序要处理的数据。定义格式：

```java
数据类型 变量名称 = 数据;
int age = 18;
```

变量的特点是**里面装的数据可以被替换**，这正是它的价值——用变量记住要处理的数据，程序写起来更灵活、管理更方便：

```java
int age = 18;
age = 19;        // 替换数据
age = age + 1;   // 在原有基础上运算后再存回去
```

### 4. 关键字与标识符

- **关键字**：Java 语言自己占用、有特殊作用的词汇（`public`、`class`、`int`、`static` 等），不能拿来当类名、变量名，否则报错。
- **标识符**：就是名字（类名、变量名、方法名都是标识符）。规则：由数字、字母、下划线 `_`、美元符 `$` 组成；不能以数字开头；不能是关键字；不能包含 `&`、`%`、`#` 等特殊字符。约定：变量名首字母小写、类名首字母大写，都遵循驼峰模式。

### 5. 数据类型：4 大类 8 种基本类型

| 分类 | 类型 | 内存占用（字节） | 数据范围 |
| --- | --- | --- | --- |
| 整型 | byte | 1 | -128 ~ 127 |
| | short | 2 | -32768 ~ 32767 |
| | int（默认） | 4 | 约 ±21 亿 |
| | long | 8 | 19 位数级别 |
| 浮点型 | float | 4 | 单精度 |
| | double（默认） | 8 | 双精度 |
| 字符型 | char | 2 | 0 ~ 65535 |
| 布尔型 | boolean | 1 | true / false |

随手写的整数字面量默认是 `int`，加 `L/l` 后缀才是 `long`；小数字面量默认是 `double`，加 `F/f` 后缀才是 `float`。

### 6. 类型转换的三种形态

- **自动类型转换**：类型范围小的变量可以直接赋值给类型范围大的变量。方向为 `byte → short/char → int → long → float → double`。
- **强制类型转换**：大范围类型的数据赋值给小范围变量会报错，必须强行转换，格式为 `目标类型 变量 = (目标类型) 数据;`。
- **表达式的自动类型提升**：在表达式中，小范围类型的变量会自动转换成表达式中较大范围的类型再参与运算；`byte`、`short`、`char` 在表达式中一律先提升为 `int`。

### 7. 键盘录入：Scanner

程序要读取用户键盘输入的数据，使用 JDK 提供的 `Scanner`（一种现成 API，配 API 文档可查）。三步走：导包 → 创建扫描器对象 → 调用方法接收数据。

## 二、技术点之间的联系

- 字面量是"数据的书写格式"，变量是"数据的容器"，数据类型则是"容器的规格"——三者共同回答一个问题：数据在 Java 程序里怎么写、怎么存。
- 数据类型的范围差异是类型转换存在的根本原因：小杯子的水可以倒进大杯子（自动转换），大杯子的水倒进小杯子可能溢出（强制转换可能丢数据）。
- 表达式自动类型提升是自动类型转换在运算场景下的延伸；而扩展赋值运算符（`+=` 等）底层隐含了强制类型转换，把"运算—提升—赋值"三步压缩成一步。
- 字符类型 `char` 之所以能和整数互相转换，是因为字符在计算机底层存的就是编码表（如 ASCII）中的数字：`'A'` 是 65、`'a'` 是 97、`'0'` 是 48。这也是 `int` 与 `char` 混算不报错的原因。
- Scanner 录入的数据进入变量，变量再参与运算和流程控制，构成"输入 → 处理 → 输出"的最小程序闭环。

补充背景：计算机底层用二进制存数据，逢 2 进 1；最小存储单元是字节（1B = 8bit），其上是 KB、MB、GB（均按 1024 进位）。Java 支持直接书写二进制（`0B` 开头）、八进制（`0` 开头）、十六进制（`0X` 开头）的字面量，便于观察二进制。

## 三、方法与实现要点

### 1. 变量使用的注意事项

- 变量必须先声明并初始化后才能使用；
- 变量有其有效范围（所在的大括号内），出范围即失效；
- 同一范围内不能定义重名变量；
- 变量定义时可以没有初始值，但使用前必须赋值。

### 2. 自动类型转换

```java
byte a = 12;
int b = a;        // 小范围 → 大范围，自动完成
long c = b;
double d = c;
```

底层原理是把小空间里的二进制位原样放进更大的空间里，高位补零，数据不变。

### 3. 强制类型转换

```java
int a = 20;
byte b = (byte) a;   // 20，正常
int i = 1500;
byte j = (byte) i;   // -36，数据溢出
```

格式：`目标类型 变量 = (目标类型) 数据;`。两个坑必须记住：

- **可能数据溢出/丢失**：大范围数据截断塞进小空间，高位被砍掉，值就变了（1500 强转成 byte 得到 -36）；
- **浮点强转整数直接丢掉小数部分**，不是四舍五入。

### 4. 表达式的自动类型提升

```java
byte a = 10;
int b = 20;
long c = 30;
long rs = a + b + c;      // 结果类型由表达式中最高类型决定

byte x = 10;
byte y = 20;
int z = x + y;            // byte + byte 结果是 int，不能再用 byte 接收
```

规则：表达式最终结果类型由表达式中的最高类型决定；`byte`、`short`、`char` 参与运算时二话不说先提升成 `int`，因为它们太容易越界。

### 5. Scanner 键盘录入三步

```java
import java.util.Scanner;            // 1. 导包（java.lang 包下的类不用导）

public class Test {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);   // 2. 创建扫描器对象

        System.out.println("请输入您的年龄：");
        int age = sc.nextInt();                 // 3. 接收整数

        System.out.println("请输入您的名称：");
        String name = sc.next();                // 接收字符串
        System.out.println("欢迎：" + name);
    }
}
```

## 四、重点与难点分析

### 重点 1：默认类型意识

整数字面量默认 `int`、小数字面量默认 `double`。写 `long l = 10000000000;` 会编译报错，因为右侧先按 `int` 解读已越界，必须写 `10000000000L`；写 `float f = 3.14;` 同样报错，必须写 `3.14F`。

### 重点 2：byte 的边界

`byte` 范围只有 -128 ~ 127，是溢出事故的高发区。给它赋字面量 `127` 可以，赋 `128` 直接编译错；把 `int` 强转成 `byte` 时更要预判结果是否还在范围内。

### 难点 1：强制转换的截断逻辑

强转不是"四舍五入"也不是"取模"，而是**二进制位的直接截断**：保留目标类型的低 N 位，高位丢弃，再按补码解释。理解这一点才能解释 `(byte)1500 == -36` 这类结果。工程建议：慎用或者不用强转，先放大容器。

### 难点 2：表达式提升的隐蔽性

`byte + byte` 得 `int`、`char + int` 得 `int` 这类提升在编译期悄然发生。写 `byte b = b1 + b2;` 会报错，新手常困惑"两个 byte 相加为什么不是 byte"。记法：小于 int 的类型参与运算，结果至少是 int。

### 易错点清单

- 字符用单引号且只能一个字符，字符串用双引号，混用报错；
- `23` 是 int，`23L` 是 long；`23.8` 是 double，`23.8F` 是 float；
- 变量未初始化就使用，编译报错；
- `Scanner` 需要 `import java.util.Scanner;`，而 `System`、`String` 在 `java.lang` 包下无需导包。

## 五、示例

### 示例 1：三种注释与编译后消失

```java
/**
 * 这是一个文档注释，通常用在类和方法上方
 */
public class CommentDemo {
    public static void main(String[] args) {
        // 下面是一行输出，往控制台打印一下我的心情
        System.out.println("开始正式学Java程序");

        /*
           这是一个
           多行注释
        */
        System.out.println("注释不影响执行");
    }
}
```

`javac` 编译后得到的 `CommentDemo.class` 中已没有任何注释，这就是"注释不影响程序执行"的直接证据。

### 示例 2：变量的替换特性

```java
int age = 18;
System.out.println(age);   // 18
age = 19;
System.out.println(age);   // 19
age = age + 1;
System.out.println(age);   // 20
```

### 示例 3：强制类型转换的溢出

```java
int i = 1500;
byte j = (byte) i;
System.out.println(j);     // -36：1500 的二进制被截断后按补码解释
```

### 示例 4：外卖优惠计算（运算符与变量综合）

需求：鱼香肉丝单点 24 元、油炸花生米 8 元、米饭 3 元；订单满 30 元打 8 折；鱼香肉丝另有优惠价 16 元，但优惠价与折扣不能同用。求最少花费。

```java
public static void goShopping(){
    // 1.定义 鱼香肉丝、油炸花生、米饭 三种菜品的价格
    int fish = 24;
    int chicken = 8;
    int rice = 3;
    // 2.定义sum变量 存放三个菜品全购买的价格
    int sum = fish + chicken + rice;
    // 3.判断 优惠价和折扣不能同时使用时 使用哪种方式价格更低
    double money = (sum * 0.8) < (sum - 16) ? (sum * 0.8) : (sum - 16);
    // 4.打印输出最终结果
    System.out.println("这个小伙要花：" + money);
}
```

### 示例 5：键盘录入与数值拆分

需求：键盘录入一个三位数，拆出个位、十位、百位分别打印。

```java
public static void main(String[] args) {
    // 1.键盘录入一个三位数
    System.out.println("请输入一个三位数：");
    Scanner sc = new Scanner(System.in);
    int a = sc.nextInt();
    // 2.调用方法进行数值打印
    numPrint(a);
}

public static void numPrint(int a){
    // 进行数值拆分：% 取余拿低位，/ 取商去低位
    int ge = a % 10;
    int shi = a / 10 % 10;
    int bai = a / 100 % 10;
    System.out.println("个位是:" + ge);
    System.out.println("十位是:" + shi);
    System.out.println("百位是:" + bai);
}
```

### 示例 6：表达式自动提升的验证

```java
byte b1 = 10;
byte b2 = 20;
// byte b3 = b1 + b2;    // 编译报错：byte/short/char 运算先提升为 int
int b3 = b1 + b2;         // 正确接收方式

char ch = 'a';            // 'a' 对应 ASCII 编码 97
System.out.println(ch + 1);  // 98：char 提升为 int 参与运算
```
