- **快速过一遍**：按 Day01→Day09 顺序读讲义，每篇末尾的「相关笔记」里有对应的课堂问答与精讲入口；
- **查漏补缺**：直接进对应主题文件夹（基础语法与流程控制 / 面向对象 / 集合框架），那里有按主题沉淀的精讲笔记；
- **面试冲刺**：结合 [[Memo/development/programming/java/java-basics-mindmap.md|Java 基础思维导图]] 与 [[Memo/development/programming/java/comprehensive-review.md|综合复习]] 做整体回顾。
