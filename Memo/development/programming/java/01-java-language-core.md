# 01 Java 语言核心

> 聚合自 Java 基础（day01-08）与 Java 进阶（接口/集合/Stream/IO/线程/网络编程）的全部笔记、Blog 与 QA，按知识域重新组织。

## 一、基础语法与流程控制

- Java 入门：开发环境搭建、第一个程序、注释与关键字
- 基础语法：数据类型、类型转换、运算符、变量与常量
- 程序流程控制：顺序/分支/循环结构
- 嵌套循环、数组与二维数组

## 二、面向对象

- 面向对象三大特征：封装、继承、多态（使用场景与注意事项）
- static 关键字的用法
- 继承的好处与注意事项；重写（Override）与重载（Overload）的区别
- 抽象类的定义与使用
- 接口：JDK1.5/1.8/9 接口成员演进；接口与抽象类的区别；接口为什么不能有构造函数
- 内部类与 Lambda：lambda 与匿名内部类的区别
- String 类常用方法；StringBuilder 介绍
- 面向对象编程实践要点

## 三、集合体系

- Collection 体系结构与常见功能
- 单列集合遍历方式（迭代器、增强 for、forEach）
- List / Set 特点与使用
- Collections 工具类
- Map 常用功能与遍历方式
- 集合底层原理：hash 值、HashMap 存储数据的过程、并发修改异常的原因

## 四、泛型、方法引用与异常

- 方法引用：引用成员方法、静态方法、特殊方法、构造函数
- 异常体系：JVM 处理异常的态度；作为使用者/定义者两种角色的异常处理；自定义异常
- 泛型：泛型类的定义与使用

## 五、Stream 流

- Stream 介绍与使用注意事项
- 获取 Stream 流对象的三种方式
- Stream 流的功能（中间操作与终结操作）

## 六、IO 体系

- File 类的常用操作
- IO 体系结构总览
- 字节流与字符流的使用

## 七、多线程与线程池

- 线程概念与创建方式
- 线程常用方法与线程状态转换
- 多线程操作共享数据的安全问题
- 线程池：七大参数、拒绝策略的种类与选择
- sleep 与 wait 的区别

## 八、网络编程

- TCP 三次握手与四次挥手
- 网络编程基础实践

## 九、JVM 与底层机制

- JVM 内存结构
- 类加载器分类与加载过程
- 反射：概念、使用前提、获取字节码的几种方式
- 动态代理：JDK 动态代理与 CGLIB 字节码生成技术的核心对比
- volatile 关键字
- 位运算基础
- Java 精准小数与超大值处理（BigDecimal / BigInteger）
