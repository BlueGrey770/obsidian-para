
**Obsidian 笔记添加属性功能。**

## 方法一：通过界面添加

1. 新建并打开笔记。
2. 按 **`Ctrl + ;`**，或按 `Ctrl + P` 搜索 **“添加文件属性 / Add file property”**。
3. 输入属性名和值；点击属性名前的图标，可以调整类型。[官方说明](https://help.obsidian.md/properties)

按家用版方案，先填两个就够：

| 属性名    | 属性类型 | 示例值          |
| ------ | ---- | ------------ |
| `type` | 文本   | `journal`    |
| `date` | 日期   | `2026-11-02` |

`type` 按内容选择：
- `log`：实践、学习和练习过程。
- `journal`：读书心得、生活随笔、思考复盘。
- `memo`：可复用知识、方法和清单。

## 方法二：直接填写源码

切换到**源码模式**，在笔记**最开头**填写：

```markdown
---
type: journal
date: 2026-11-02
---

# 我的读书笔记

这里写正文。
```

顶部两条 `---` 之间就是属性，日期替换为首次记录日期。

## 方法三：插件创建
Obsidian中可以通过插件快速实现笔记及属性规则的快速引用，但此方法需要配置模版及插件设置，配置教程及使用地址：[[obsidian-plugin-setup-guide]] 。

**注意区分：**
- **家用新版方案**：最低只需要 `type`、`date`。
- **当前工作库**：还应填写 `project`；通用内容写 `project: null`，明确项目则填写对应 ID。
- 属性面板看不到时，检查 **设置 → 编辑器 → 文档中的属性 → 显示**。[属性显示设置](https://help.obsidian.md/properties)
