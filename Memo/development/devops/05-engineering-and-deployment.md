# 05 工程化与部署

> 聚合自各课程中的环境配置、自动化部署、版本管理与项目管理材料，去除项目特定步骤，保留通用工程实践。

## 一、开发环境

- IDEA 环境配置清单：编码配置、自动导包、提示忽略大小写、Java 编译级别
- Maven：安装、仓库配置、IDEA 集成、标签含义、聚合与继承、打包部署
- 虚拟机环境：VMware 安装与虚拟机挂载、导入虚拟机、远程连接、修改 IP
- 开发环境版本选型要求

## 二、Git 版本管理

- Git 基本配置与本地仓库获取
- 基础操作指令
- 远程仓库操作
- 分支操作

## 三、自动化部署与 CI

- 代码检查插件的引入
- 项目开发模式对比
- 项目部署流程与日志管理
- Jenkins：简介、安装与构建流水线（扩展）
- 使用 Kubernetes 部署应用的名词与流程概览

## 四、容器化

- Docker 基础使用
- Docker 容器网络问题排查（IPv4 forwarding 警告）

## 五、项目管理

- 项目管理基础概念
- 禅道（开源项目管理工具）的使用

## 六、效率工具

- 常用开发快捷键汇总
- 接口文档的维护习惯（在线接口文档）
