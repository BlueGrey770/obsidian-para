# Obsidian 笔记属性：给笔记加 type 与 date

本库所有正式笔记靠属性区分体裁和日期，属性写在文件开头的 YAML 区（两行 `---` 之间）。三种填法，日常用第一种即可。

## 方法一：通过界面添加

1. 新建并打开笔记。
2. 按 **`Ctrl + ;`**，或按 `Ctrl + P` 搜索 **“添加文件属性 / Add file property”**。
3. 输入属性名和值；点击属性名前的图标，可以调整类型。[官方说明](https://help.obsidian.md/properties)

本库方案，先填两个就够：

| 属性名    | 属性类型 | 示例值        |
| ------ | ---- | ---------- |
| `type` | 文本   | `memo`     |
| `date` | 日期   | 2026-11-02 |

`type` 按内容选择：
- `log`：实践、学习和练习过程。
- `journal`：读书心得、生活随笔、思考复盘。
- `memo`：可复用知识、方法和清单。

## 方法二：直接填写源码

切换到**源码模式**，在笔记**最开头**填写：

```markdown
---
type: journal
date: 2026-11-02
---

# 我的读书笔记

这里写正文。
```

顶部两条 `---` 之间就是属性，日期替换为首次记录日期。

## 方法三：插件创建

Obsidian 中可以通过插件快速实现笔记及属性规则的快速引用，但此方法需要配置模板及插件设置，配置教程及使用地址：[[obsidian-plugin-setup-guide]] 。

**注意区分：**
- **本库最低要求**：`type`、`date` 两个字段，写法见管理规范第三节。
- **project 可省略**：只有内容明确属于某个个人项目时才填单值，日常笔记不要为了“填全”硬加。
- **导图笔记**：另有 `type: mindmap` 与四个样式键，见 [[obsidian-mindmap-plugins|思维导图插件教程]]。
- 属性面板看不到时，检查 **设置 → 编辑器 → 文档中的属性 → 显示**。[属性显示设置](https://help.obsidian.md/properties)
