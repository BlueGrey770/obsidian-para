# 03 Web 开发与框架

> 聚合自 Web 阶段全部笔记：前端基础、后端基础、数据库持久层之外的框架知识、项目实践沉淀与 Blog 题解。

## 一、前端基础

- Web 网站结构：HTML 快速入门与基本语法
- CSS 基础
- DOM 操作与动态加载数据
- 前端综合案例实践

## 二、Vue 与异步请求

- 集成 Vue 环境、Vue 常用指令及作用
- 基于 Vue 渲染页面
- Axios 入门、请求方式别名、异步请求实践
- Vue + Axios 综合案例
- Vue 工程化与组件库（Element Plus）实战
- Node.js 环境安装
- 父子组件通信

## 三、Spring 与 Spring Boot

- 初识 Spring 与 Web 入门程序
- IoC（控制反转）与 DI（依赖注入）概念及相关注解
- Spring 解决的核心问题清单
- 三层架构与开发规范
- 反射与分层解耦的原理
- Bean 冲突的三种解决方案（@Autowired + @Qualifier / 按名称注入 / 指定默认 Bean）
- 第三方 Bean 管理相关注解
- Spring Boot 自动配置原理
- 起步依赖的构成思路（自定义配置模块 + 起步依赖模块）
- 配置文件优先级

## 四、Spring MVC

- Spring MVC 执行原理（高频面试题）
- 常用注解及作用；元注解有哪些
- 请求参数封装与返回值 JSON 格式约定
- 拦截器（Interceptor）与过滤器（Filter）的区别
- Http 协议的组成部分；常见状态码

## 五、测试

- 测试用例定义与测试框架使用
- 参数化测试（重点）

## 六、会话与认证

- 会话技术：Cookie、Session、JWT 令牌对比
- 登录验证的实现思路
- ThreadLocal：概述、使用场景、基本用法与注意事项
- 用户上下文的设计（请求内传递登录用户信息）

## 七、AOP

- AOP 的作用、概念与使用步骤
- AOP 典型案例实践

## 八、异常处理与日志

- 全局异常处理的定义步骤（含部署依赖、使用原理）
- 日志框架 Logback：依赖、使用步骤与原理

## 九、文件上传

- 文件上传前端必须遵守的规则与后端处理
- 对象存储（阿里 OSS）集成与环境依赖配置

## 十、Redis 基础

- Redis 基本数据类型（String / Hash / List / Set / ZSet）与通用命令
- 在 Java 程序中使用 Redis（依赖引入、缓存设置）
