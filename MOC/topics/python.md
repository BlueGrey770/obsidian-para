# Python

本分类覆盖 Python 入门到基础进阶的完整知识链：从计算机组成与环境搭建起步，经由变量、运算符、分支、循环、函数、数据容器五大核心模块，最终落地到一个综合运用全部知识点的控制台实战项目。适合零基础起步的初学者按顺序通读，也适合作为日常开发中查阅语法细节（如容器方法清单、切片规则、传参方式）的手册。

## 学习路径

1. [[python-overview|计算机组成与 Python 概述]] — 硬件/软件系统、编程语言演进、Python 优缺点与环境搭建。
2. [[python-basics|Python 基础语法]] — 注释、变量、四大基本类型、标识符命名规范、print 格式化输出。
3. [[python-input-operators|键盘录入与运算符]] — input 录入、类型转换、算术/赋值/比较/逻辑运算符全集。
4. [[python-branching|分支判断语句]] — if/elif/else、嵌套 if、random 随机数与剪刀石头布综合案例。
5. [[python-loops|循环语句]] — while 与 for、range 序列、break/continue、嵌套循环打印九九乘法表。
6. [[python-functions|函数基础]] — 函数定义与调用、形参与实参、返回值与 None、说明文档、作用域与 global。
7. [[python-data-containers|数据容器]] — list/tuple/str/set/dict 五类容器的方法清单、切片、遍历与选型对比。
8. [[python-functions-advanced|函数进阶]] — 多返回值、位置/关键字/缺省/不定长四种传参，lambda 与闭包概念。
9. [[python-case-student-manager|综合实战：学生管理系统]] — 增删改查菜单程序的需求拆解、结构设计与踩坑复盘。
