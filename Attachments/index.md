# 附件目录与保存规则

当前只有结构，没有导入原件。

- `Attachments/development/`：开发相关原件，需要时再按主题分类。
- `Attachments/languages/`：语言材料，英语可放english。
- `Attachments/life/`：可确认保存的生活资料；敏感原件先决定安全存储。
- `Attachments/sources/books/<book-slug>/`：书籍原格式文件与必要资源。
- `Attachments/sources/exams/<exam-id>/`：考试资料与来源。

原件在领域或来源位置择一存放，其他地方引用，不重复复制。PDF、Word、Excel、音视频、完整JSON/CSV、脚本与HTML优先保留原格式；HTML与本地资源保持相对结构。Markdown用于自己的理解与独立提炼，不批量全文包装。

默认附件接收位置是Attachments，按需要再通过Obsidian分类。private只表示分类，不是加密；不因整理自动上传、执行附件代码或修改外部原文件。
